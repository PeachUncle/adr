# ADR-005: LLM Configuration Externalization

**Status**: Proposed

## Question

How do you externalize LLM configuration in llm4s?

## Context

Tripper externalizes LLM configuration in YAML/properties files:
- **Model selection**: Different models for different roles (planner vs. researcher)
- **Personas**: Role, goal, and backstory for each LLM agent
- **Parameters**: Temperature, max tokens, etc.
- **Cost controls**: Budget limits and confirmation thresholds

Configuration as code enables:
- Environment-specific tuning (dev vs. prod)
- A/B testing of different models
- Cost optimization without code changes
- Easy model upgrades

We need to determine how llm4s handles external configuration and persona management.

## Decision

Use **PureConfig with HOCON** (application.conf) to externalize all LLM configuration. llm4s uses **environment variables** for client creation, while **CompletionOptions** and **SystemMessage** handle per-request configuration.

### Architecture

```
application.conf (HOCON)
    ↓
PureConfig (type-safe loading)
    ↓
TripperConfig case classes
    ↓
LLM Client Factory (creates llm4s clients)
    ↓
Conversation Builder (SystemMessage for personas)
    ↓
CompletionOptions (per-request parameters)
```

### llm4s Configuration Model

llm4s supports configuration through:

1. **Environment Variables** - Client creation
   ```bash
   LLM_MODEL=openai/gpt-4o
   OPENAI_API_KEY=sk-...
   ```

2. **CompletionOptions** - Per-request parameters
   ```scala
   CompletionOptions(
     temperature = 0.7,
     maxTokens = Some(4000),
     topP = 1.0,
     presencePenalty = 0.0,
     frequencyPenalty = 0.0
   )
   ```

3. **SystemMessage** - Personas and prompts
   ```scala
   SystemMessage("You are a strategic travel planner...")
   ```

### Proposed Solution: Type-Safe Configuration Layer

Extend existing `TripperConfig.scala` with full configuration support:

```scala
package io.github.llm4s.tripper.config

import scala.concurrent.duration.FiniteDuration
import pureconfig._
import pureconfig.generic.derivation.default._
import org.llm4s.llmconnect.model.CompletionOptions

/**
 * Root configuration for the tripper application.
 */
final case class TripperConfig(
  llm: LLMConfig,
  personas: PersonasConfig,
  workflow: WorkflowConfig,
  output: OutputConfig,
  budget: BudgetConfig
) derives ConfigReader

/**
 * LLM configuration for different roles.
 */
final case class LLMConfig(
  planner: LLMRoleConfig,
  researcher: LLMRoleConfig
) derives ConfigReader

/**
 * Configuration for a specific LLM role.
 * Maps to llm4s CompletionOptions + environment variable format.
 */
final case class LLMRoleConfig(
  provider: String,              // openai, anthropic, azure, openrouter
  model: String,                 // gpt-4o, claude-3-7-sonnet-latest
  temperature: Double,           // 0.0 to 2.0
  maxTokens: Int,                // Maximum tokens per request
  topP: Double = 1.0,           // Nucleus sampling
  presencePenalty: Double = 0.0, // -2.0 to 2.0
  frequencyPenalty: Double = 0.0 // -2.0 to 2.0
) derives ConfigReader {
  
  /**
   * Convert to llm4s CompletionOptions.
   */
  def toCompletionOptions: CompletionOptions = CompletionOptions(
    temperature = temperature,
    topP = topP,
    maxTokens = Some(maxTokens),
    presencePenalty = presencePenalty,
    frequencyPenalty = frequencyPenalty
  )
  
  /**
   * Environment variable format for llm4s: provider/model
   */
  def toLLMModelEnv: String = s"$provider/$model"
}

/**
 * Persona configuration for different agent roles.
 * Maps to llm4s SystemMessage.
 */
final case class PersonasConfig(
  planner: PersonaConfig,
  researcher: PersonaConfig
) derives ConfigReader

final case class PersonaConfig(
  role: String,
  goal: String,
  backstory: String
) derives ConfigReader {
  
  /**
   * Generate SystemMessage for llm4s.
   */
  def toSystemMessage: String = {
    s"""Role: $role
       |
       |Goal: $goal
       |
       |Backstory: $backstory
       |""".stripMargin
  }
}

/**
 * Workflow execution configuration.
 */
final case class WorkflowConfig(
  maxConcurrency: Int,
  timeout: FiniteDuration
) derives ConfigReader

/**
 * Output formatting configuration.
 */
final case class OutputConfig(
  wordCount: Int,
  imageWidth: Int
) derives ConfigReader

/**
 * Budget and cost control configuration.
 */
final case class BudgetConfig(
  maxTokensPerRequest: Int,
  confirmationThreshold: Double // USD
) derives ConfigReader
```

### Configuration Loading with PureConfig

```scala
package io.github.llm4s.tripper.config

import cats.effect.IO
import pureconfig._
import pureconfig.module.catseffect.syntax._

object ConfigLoader {
  
  /**
   * Load configuration from application.conf.
   */
  def load: IO[TripperConfig] = {
    ConfigSource.default
      .at("tripper")
      .loadF[IO, TripperConfig]()
  }
  
  /**
   * Load with fallback to default configuration.
   */
  def loadWithDefault(default: TripperConfig): IO[TripperConfig] = {
    load.handleErrorWith { error =>
      IO.println(s"Failed to load config: ${error.getMessage}") >>
      IO.println("Using default configuration") >>
      IO.pure(default)
    }
  }
}
```

### LLM Client Factory

Create clients based on configuration:

```scala
package io.github.llm4s.tripper.llm

import cats.effect.IO
import org.llm4s.llmconnect.{LLM, LLMClient, LLMConnect}
import org.llm4s.llmconnect.model.{CompletionOptions, SystemMessage, Conversation}
import io.github.llm4s.tripper.config.{TripperConfig, LLMRoleConfig, PersonaConfig}

/**
 * Factory for creating configured LLM clients.
 */
object LLMClientFactory {
  
  /**
   * Create a client for a specific role using environment variables.
   * Sets LLM_MODEL environment variable and creates client.
   */
  def createClient(roleConfig: LLMRoleConfig): IO[LLMClient] = IO {
    // Set environment variable for llm4s
    System.setProperty("LLM_MODEL", roleConfig.toLLMModelEnv)
    LLM.client()
  }
  
  /**
   * Create planner client from config.
   */
  def createPlannerClient(config: TripperConfig): IO[LLMClient] = {
    createClient(config.llm.planner)
  }
  
  /**
   * Create researcher client from config.
   */
  def createResearcherClient(config: TripperConfig): IO[LLMClient] = {
    createClient(config.llm.researcher)
  }
  
  /**
   * Get CompletionOptions for a role.
   */
  def getCompletionOptions(roleConfig: LLMRoleConfig): CompletionOptions = {
    roleConfig.toCompletionOptions
  }
  
  /**
   * Build conversation with persona system message.
   */
  def buildConversation(
    persona: PersonaConfig,
    userMessages: String*
  ): Conversation = {
    val systemMsg: SystemMessage = SystemMessage(persona.toSystemMessage)
    val userMsgs: Seq[UserMessage] = userMessages.map(UserMessage(_))
    Conversation(systemMsg +: userMsgs)
  }
}

/**
 * Pre-configured LLM clients for the application.
 */
class ConfiguredClients(config: TripperConfig) {
  
  val plannerClient: IO[LLMClient] = 
    LLMClientFactory.createPlannerClient(config)
  
  val researcherClient: IO[LLMClient] = 
    LLMClientFactory.createResearcherClient(config)
  
  val plannerOptions: CompletionOptions = 
    config.llm.planner.toCompletionOptions
  
  val researcherOptions: CompletionOptions = 
    config.llm.researcher.toCompletionOptions
  
  val plannerPersona: PersonaConfig = config.personas.planner
  val researcherPersona: PersonaConfig = config.personas.researcher
}
```

### Usage in Workflows

```scala
package io.github.llm4s.tripper.workflow

import cats.effect.IO
import workflows4s.wio.WIO
import org.llm4s.llmconnect.model.{Conversation, UserMessage}
import io.github.llm4s.tripper.config.{TripperConfig, ConfigLoader}
import io.github.llm4s.tripper.llm.{LLMClientFactory, ConfiguredClients}

object TravelPlanningWorkflow {
  
  /**
   * Create workflow with configuration.
   */
  def create: IO[WIO.Initial] = for {
    config <- ConfigLoader.load
    clients = new ConfiguredClients(config)
  } yield buildWorkflow(clients, config)
  
  private def buildWorkflow(
    clients: ConfiguredClients,
    config: TripperConfig
  ): WIO.Initial = {
    
    // Planner step - uses high-quality model
    val plannerStep: WIO[State, Nothing, State] = WIO
      .runIO[State] { state =>
        for {
          client <- clients.plannerClient
          
          // Build conversation with persona
          conversation = LLMClientFactory.buildConversation(
            clients.plannerPersona,
            s"Create travel plan for: ${state.travelBrief.destination}"
          )
          
          // Call LLM with configured options
          result <- IO.delay {
            client.complete(conversation, clients.plannerOptions)
          }
        } yield result match {
          case Right(completion) => PlanGenerated(completion.message.content)
          case Left(error) => PlanError(error.message)
        }
      }
      .handleEvent { (state, event) =>
        event match {
          case PlanGenerated(plan) => state.copy(proposedPlan = Some(plan))
          case PlanError(msg) => state.copy(error = Some(msg))
        }
      }
      .named("Generate Travel Plan (Planner)")
    
    // Researcher step - uses cost-effective model for parallel research
    val researcherStep: WIO[State, Nothing, State] = WIO
      .runIO[State] { state =>
        for {
          client <- clients.researcherClient
          semaphore <- cats.effect.std.Semaphore[IO](config.workflow.maxConcurrency)
          
          // Research POIs in parallel with configured concurrency
          researched <- state.pointsOfInterest.parTraverse { poi =>
            semaphore.permit.use { _ =>
              val conversation = LLMClientFactory.buildConversation(
                clients.researcherPersona,
                s"Research: ${poi.name}"
              )
              
              IO.delay {
                client.complete(conversation, clients.researcherOptions)
              }.map {
                case Right(completion) => 
                  ResearchedPointOfInterest(poi, completion.message.content)
                case Left(error) =>
                  ResearchedPointOfInterest(poi, s"Error: ${error.message}")
              }
            }
          }
        } yield AllPOIsResearched(researched)
      }
      .handleEvent { (state, event) =>
        state.copy(researchedPOIs = event.researched)
      }
      .named("Research Points of Interest (Researcher)")
    
    // Compose workflow
    plannerStep >>> researcherStep
  }
}
```

## Consequences

### Positive

1. **Type-safe configuration**: PureConfig ensures compile-time correctness
2. **Environment-specific**: Easy to override for dev/staging/prod
3. **Centralized**: All configuration in one place
4. **Flexible model selection**: Switch models without code changes
5. **Persona management**: System prompts externalized and versioned
6. **Cost control**: Token limits and thresholds configurable
7. **Testing**: Easy to create test configurations
8. **Documentation**: Configuration file documents all options

### Negative

1. **Environment variable coupling**: llm4s requires LLM_MODEL env var
2. **Dual configuration**: PureConfig + environment variables
3. **Runtime property setting**: Must set System.setProperty for llm4s
4. **No hot reload**: Configuration changes require restart
5. **Validation complexity**: Must validate configuration at load time

### Trade-offs

- **llm4s limitation**: Uses environment variables for client creation
- **Workaround**: Set System properties programmatically from config
- **Alternative**: Could use llm4s `LLMConnect.getClient(provider, config)` directly
- **Choice**: Hybrid approach balances type safety with llm4s conventions

libraryDependencies ++= Seq(

### 2. Extend TripperConfig.scala

Add persona configuration and conversion methods as shown above.

### 3. Create ConfigLoader

Implement configuration loading with error handling.

### 4. Create LLMClientFactory

Factory for creating configured clients and conversations.

### 5. Update Main.scala

Load configuration on startup:

```scala
object Main extends IOApp {
  def run(args: List[String]): IO[ExitCode] = for {
    logger <- Slf4jLogger.create[IO]
    config <- ConfigLoader.load
    _ <- logger.info(s"Loaded configuration: planner=${config.llm.planner.model}, researcher=${config.llm.researcher.model}")
    
    // Create workflow with configuration
    workflow <- TravelPlanningWorkflow.create
    
    // Run workflow...
  } yield ExitCode.Success
}
```
