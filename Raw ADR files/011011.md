# ADR-004: Commercial LLM Escalation Policy

## Status
**Accepted** - January 2024

## Context

The Marina system is designed primarily for local processing with privacy-first principles. However, there are scenarios where the local AI models may not be sufficient for optimal therapeutic support, requiring temporary escalation to commercial LLMs (GPT-4, Claude, etc.) for enhanced reasoning capabilities.

Key considerations:
1. **Privacy vs. Capability Trade-off**: When is it justified to use external services?
2. **User Consent**: How to handle user preferences for privacy vs. enhanced support?
3. **Data Minimization**: What minimal data is needed for effective external processing?
4. **Audit Requirements**: Complete traceability of all external processing decisions
5. **Cost Management**: Controlling expenses from commercial API usage
6. **Fallback Strategy**: Ensuring system continues working if external services fail
7. **Therapeutic Effectiveness**: Balancing privacy with potentially better outcomes

## Decision

We will implement a **selective escalation policy** that uses commercial LLMs only when specific conditions are met, with strict privacy controls and user consent requirements.

### Escalation Framework

```python
from enum import Enum
from dataclasses import dataclass
from typing import Optional, List

class EscalationReason(Enum):
    LOW_CONFIDENCE = "low_confidence"
    COMPLEX_REASONING = "complex_reasoning"  
    REPEATED_FAILURES = "repeated_failures"
    DELIRANT_CONTRADICTIONS = "delirant_contradictions"
    CRISIS_COMPLEXITY = "crisis_complexity"
    USER_REQUESTED = "user_requested"

class EscalationRole(Enum):
    EVALUATOR = "evaluator"      # Assess situation and recommend approach
    RESPONDER = "responder"      # Generate actual therapeutic response
    ADVISOR = "advisor"          # Provide guidance to local agent

@dataclass
class EscalationTrigger:
    reason: EscalationReason
    threshold: float
    required_confidence: float
    max_context_tokens: int
    user_consent_required: bool
    audit_level: str

# Escalation configuration
ESCALATION_TRIGGERS = {
```

### Escalation Decision Engine

```python
class EscalationDecisionEngine:
    def __init__(self, privacy_engine: PrivacyDecisionEngine):
        self.privacy_engine = privacy_engine
        self.failure_tracker = FailureTracker()
        self.audit_logger = EscalationAuditLogger()
    
    async def should_escalate(
        self,
        context: RoutingContext,
        classification_result: ClassificationResult,
        previous_attempts: List[dict]
    ) -> EscalationDecision:
        """Determine if escalation to commercial LLM is warranted"""
        
        potential_reasons = await self._evaluate_escalation_triggers(
            context, classification_result, previous_attempts
        )
        
        if not potential_reasons:
            return EscalationDecision(
                should_escalate=False,
                reason="No escalation triggers met"
            )
        
        # Select highest priority reason
        primary_reason = self._select_primary_reason(potential_reasons)
        trigger = ESCALATION_TRIGGERS[primary_reason]
        
        # Check user consent requirements
        consent_result = await self._check_user_consent(
            context.user_id, trigger, primary_reason
        )
        
        if not consent_result.granted:
            return EscalationDecision(
                should_escalate=False,
                reason=f"User consent not granted: {consent_result.reason}",
                consent_required=True
            )
        
        # Validate privacy requirements
        privacy_result = await self.privacy_engine.can_process_externally(
            context.user_input,
            ProcessingContext(
                user_id=context.user_id,
                processing_reason=f"escalation_{primary_reason.value}",
                max_tokens=trigger.max_context_tokens,
                requires_full_history=False
            ),
            consent_result.consent_profile
        )
        
        if not privacy_result.allowed:
            return EscalationDecision(
                should_escalate=False,
                reason=f"Privacy requirements not met: {privacy_result.reason}",
                privacy_blocked=True
            )
        
        # Determine escalation role
        escalation_role = self._determine_escalation_role(
            primary_reason, classification_result
        )
        
        return EscalationDecision(
            should_escalate=True,
            reason=primary_reason,
            role=escalation_role,
            context_data=privacy_result.redacted_data,
            confidence_threshold=trigger.required_confidence,
            audit_level=trigger.audit_level,
            estimated_cost=self._estimate_cost(trigger.max_context_tokens)
        )
    
    async def _evaluate_escalation_triggers(
        self,
        context: RoutingContext,
        classification: ClassificationResult,
        previous_attempts: List[dict]
    ) -> List[EscalationReason]:
        """Evaluate all potential escalation triggers"""
        triggers = []
        
        # Low confidence trigger
        if classification.confidence < ESCALATION_TRIGGERS[EscalationReason.LOW_CONFIDENCE].threshold:
            triggers.append(EscalationReason.LOW_CONFIDENCE)
        
        # Complex reasoning trigger (long context)
        context_length = len(context.user_input.split()) + sum(
            len(msg.get('content', '').split()) for msg in context.conversation_history
        )
        if context_length > ESCALATION_TRIGGERS[EscalationReason.COMPLEX_REASONING].threshold:
            triggers.append(EscalationReason.COMPLEX_REASONING)
        
        # Repeated failures trigger
        recent_failures = await self.failure_tracker.get_recent_failures(
            context.user_id, minutes=30
        )
        if len(recent_failures) >= ESCALATION_TRIGGERS[EscalationReason.REPEATED_FAILURES].threshold:
            triggers.append(EscalationReason.REPEATED_FAILURES)
        
        # Delirant contradictions trigger
        if (classification.state == AffectiveState.DELIRANT and 
            await self._detect_contradictions(context)):
            triggers.append(EscalationReason.DELIRANT_CONTRADICTIONS)
        
        # Crisis complexity trigger
        if (context.safety_assessment.risk_level == RiskLevel.HIGH and
            await self._assess_crisis_complexity(context)):
            triggers.append(EscalationReason.CRISIS_COMPLEXITY)
        
        return triggers
    
    def _determine_escalation_role(
        self, 
        reason: EscalationReason, 
        classification: ClassificationResult
    ) -> EscalationRole:
        """Determine what role the commercial LLM should play"""
        
        role_mapping = {
            EscalationReason.LOW_CONFIDENCE: EscalationRole.EVALUATOR,
            EscalationReason.COMPLEX_REASONING: EscalationRole.ADVISOR,
            EscalationReason.REPEATED_FAILURES: EscalationRole.RESPONDER,
            EscalationReason.DELIRANT_CONTRADICTIONS: EscalationRole.ADVISOR,
            EscalationReason.CRISIS_COMPLEXITY: EscalationRole.RESPONDER,
            EscalationReason.USER_REQUESTED: EscalationRole.RESPONDER
        }
        
        return role_mapping.get(reason, EscalationRole.ADVISOR)
```

### Commercial LLM Integration

```python
class CommercialLLMService:
    def __init__(self, config: CommercialLLMConfig):
        self.config = config
        self.providers = {
            "openai": OpenAIProvider(config.openai),
            "anthropic": AnthropicProvider(config.anthropic)
        }
        self.audit_logger = EscalationAuditLogger()
        
    async def process_escalation(
        self, 
        escalation_decision: EscalationDecision,
        context: RoutingContext
    ) -> EscalationResult:
        """Process escalation request through commercial LLM"""
        
        # Start audit trail
        audit_id = await self.audit_logger.start_escalation_audit(
            user_id=context.user_id,
            reason=escalation_decision.reason,
            role=escalation_decision.role,
            provider=self.config.default_provider,
            context_size=len(escalation_decision.context_data)
        )
        
        try:
            # Prepare specialized prompt based on role
            prompt = await self._prepare_escalation_prompt(
                escalation_decision.role,
                escalation_decision.context_data,
                context
            )
            
            # Select provider (with fallback)
            provider = await self._select_provider(escalation_decision.reason)
            
            # Make API call with timeout and retries
            api_result = await self._call_commercial_api(
                provider, prompt, escalation_decision.audit_level
            )
            
            # Validate and filter response
            filtered_response = await self._filter_commercial_response(
                api_result.response, context
            )
            
            # Create local integration response
            local_response = await self._integrate_with_local_agent(
                filtered_response, 
                escalation_decision.role,
                context
            )
            
            # Complete audit trail
            await self.audit_logger.complete_escalation_audit(
                audit_id=audit_id,
                success=True,
                response_size=len(filtered_response),
                cost=api_result.estimated_cost,
                latency=api_result.processing_time
            )
            
            return EscalationResult(
                success=True,
                response=local_response,
                metadata=EscalationMetadata(
                    provider=provider.name,
                    role=escalation_decision.role,
                    cost=api_result.estimated_cost,
                    processing_time=api_result.processing_time,
                    audit_id=audit_id
                )
            )
            
        except Exception as e:
            await self.audit_logger.log_escalation_error(audit_id, str(e))
            
            # Fallback to local processing
            return await self._fallback_to_local(context, escalation_decision)
    
    async def _prepare_escalation_prompt(
        self,
        role: EscalationRole,
        context_data: str,
        context: RoutingContext
    ) -> str:
        """Prepare specialized prompt based on escalation role"""
        
        base_context = f"""
        Context: You are assisting a Russian-speaking therapeutic AI system.
        
        Current situation:
        - User input (redacted): {context_data}
        - Affective state: {context.affective_state.state.value}
        - Safety level: {context.safety_assessment.risk_level.value}
        
        Important constraints:
        - Respond in Russian
        - Follow therapeutic best practices
        - No diagnostic statements
        - Prioritize user safety
        """
        
        if role == EscalationRole.EVALUATOR:
            return base_context + """
            Your role: Evaluate the situation and recommend the best therapeutic approach.
            
            Please provide:
            1. Assessment of the user's current state
            2. Recommended therapeutic strategy
            3. Specific response approach suggestions
            4. Any safety considerations
            
            Format: JSON with keys: assessment, strategy, approach, safety
            """
            
        elif role == EscalationRole.RESPONDER:
            return base_context + """
            Your role: Generate a direct therapeutic response to the user.
            
            Requirements:
            - Empathetic and professional tone
            - Appropriate for the detected affective state
            - Include a helpful micro-action or reflection
            - Keep response concise (2-3 sentences)
            
            Generate the response that a skilled therapist would give.
            """
            
        elif role == EscalationRole.ADVISOR:
            return base_context + """
            Your role: Provide guidance to the local AI agent.
            
            Please advise on:
            1. How to interpret the user's communication
            2. What therapeutic techniques to apply
            3. Potential pitfalls to avoid
            4. Follow-up strategies
            
            Format: JSON with keys: interpretation, techniques, pitfalls, followup
            """
    
    async def _fallback_to_local(
        self, 
        context: RoutingContext,
        escalation_decision: EscalationDecision
    ) -> EscalationResult:
        """Fallback to local processing when external escalation fails"""
        
        # Use most appropriate local agent
        fallback_agent = self._select_fallback_agent(context.affective_state)
        
        # Generate response with "best effort" flag
        local_response = await fallback_agent.generate_response(
            AgentContext(
                user_input=context.user_input,
                conversation_history=context.conversation_history[-5:],  # Limit context
                user_profile=context.user_profile,
                affective_state=context.affective_state,
                safety_assessment=context.safety_assessment,
                session_metadata={"escalation_fallback": True}
            )
        )
        
        return EscalationResult(
            success=False,
            response=local_response,
            fallback_used=True,
            metadata=EscalationMetadata(
                provider="local_fallback",
                role=escalation_decision.role,
                cost=0.0,
                processing_time=local_response.processing_time,
                audit_id=None
            )
        )
```

### Cost Management and Budgeting

```python
class EscalationCostManager:
    def __init__(self, config: CostConfig):
        self.config = config
        self.usage_tracker = UsageTracker()
    
    async def check_budget_constraints(
        self, 
        user_id: UUID,
        estimated_cost: float
    ) -> BudgetCheckResult:
        """Check if escalation is within budget limits"""
        
        # Check daily user limit
        daily_usage = await self.usage_tracker.get_daily_usage(user_id)
        if daily_usage.cost + estimated_cost > self.config.daily_user_limit:
            return BudgetCheckResult(
                allowed=False,
                reason="Daily user budget limit exceeded",
                remaining_budget=max(0, self.config.daily_user_limit - daily_usage.cost)
            )
        
        # Check monthly system limit
        monthly_usage = await self.usage_tracker.get_monthly_system_usage()
        if monthly_usage.cost + estimated_cost > self.config.monthly_system_limit:
            return BudgetCheckResult(
                allowed=False,
                reason="Monthly system budget limit exceeded",
                remaining_budget=max(0, self.config.monthly_system_limit - monthly_usage.cost)
            )
        
        return BudgetCheckResult(
            allowed=True,
            remaining_budget=min(
                self.config.daily_user_limit - daily_usage.cost,
                self.config.monthly_system_limit - monthly_usage.cost
            )
        )

# Cost configuration
cost_config = CostConfig(
    daily_user_limit=5.00,      # $5 per user per day
    monthly_system_limit=1000.0, # $1000 per month system-wide
    emergency_multiplier=2.0,    # 2x limit for crisis situations
    token_costs={
        "openai_gpt4": 0.00003,     # $0.03 per 1K tokens
        "anthropic_claude": 0.00025  # $0.25 per 1K tokens
    }
)
```

## Consequences

### Positive Outcomes:
1. **Enhanced Capability**: Access to state-of-the-art reasoning for complex cases
2. **Improved Outcomes**: Better therapeutic responses in challenging situations
3. **User Choice**: Granular control over privacy vs. capability trade-offs
4. **Cost Control**: Built-in budgeting and cost management
5. **Audit Trail**: Complete transparency for all external processing
6. **Fallback Resilience**: System continues working if external services fail

### Challenges and Risks:
1. **Privacy Concerns**: External processing of sensitive therapeutic data
2. **Cost Management**: Potential for expensive API usage
3. **Dependency Risk**: Reliance on external service availability
4. **Consistency**: Different response styles between local and commercial models
5. **Latency Impact**: Additional processing time for external calls
6. **Consent Complexity**: User confusion about when escalation occurs

### Mitigation Strategies:
1. **Strict Privacy Controls**: Minimal data sharing with comprehensive redaction
2. **Budget Enforcement**: Hard limits with user and system-level controls
3. **Robust Fallbacks**: Always maintain local processing capability
4. **Response Integration**: Standardize response format across all sources
5. **Performance Optimization**: Parallel processing and caching where possible
6. **User Education**: Clear explanations of escalation benefits and privacy protections

## Monitoring and Success Metrics

### Key Performance Indicators:
- **Escalation Rate**: <15% of total conversations
- **User Satisfaction**: Escalated conversations rated >4.5/5
- **Cost Efficiency**: Average cost per escalation <$2.00
- **Privacy Compliance**: 100% of escalations properly audited
- **Fallback Success**: >95% successful fallbacks when external services fail
- **User Consent Rate**: >80% of eligible users consent to escalation

### Operational Metrics:
- **API Latency**: External calls complete <5s
- **Cost Overruns**: Monthly budget variance <10%
- **Privacy Violations**: Zero incidents of improper data sharing
- **Audit Completeness**: 100% of escalations fully logged

---

*This ADR establishes a balanced approach to commercial LLM escalation that preserves user privacy while providing access to advanced AI capabilities when most needed for therapeutic effectiveness.*
