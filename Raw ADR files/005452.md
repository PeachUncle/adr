## Context

The multi-agent trading system has a placeholder for a `Bearish Strategy Agent` but lacks a defined strategy. The `Stock Selection Agent` can identify candidates with a "Bearish" bias, but the system currently has no way to act on this analysis. A defined-risk strategy is required to capitalize on these opportunities while adhering to the system's risk management principles.

## Decision

We will implement the **Bear Call Spread** as the primary bearish strategy.

### Rationale

1.  **Risk-Defined**: Like the Iron Condor, the Bear Call Spread has a defined maximum profit and maximum loss, which aligns perfectly with the system's emphasis on quantifiable risk. This makes it easy to integrate with the `Risk Management Agent`.
2.  **Complements Existing Strategies**: It is a credit spread, similar to the short sides of the Iron Condor, making the logic for premium calculation, strike selection (based on resistance), and risk management highly compatible with existing patterns.
3.  **High Probability**: When selling out-of-the-money, it is a high-probability strategy that profits from a decrease in the underlying's price, a sideways movement, or even a slight increase, as long as the price stays below the short strike. This aligns with the goal of generating consistent income.
4.  **Capital Efficiency**: As a spread, it requires less capital (margin) than selling a naked call, allowing for better capital allocation across the portfolio.

### Alternatives Considered

-   **Long Put**: A simpler strategy, but it is a debit strategy with a lower probability of profit and suffers from time decay (theta). It does not align as well with the system's primary goal of income generation.
-   **Naked Call**: Unlimited risk, which violates the core principle of using only risk-defined strategies. Rejected outright.
-   **Bear Put Spread**: A debit spread with defined risk, but requires paying premium upfront (theta negative). Bear Call Spread is preferred as a credit spread (theta positive) that aligns with income generation goals.

## Implementation Strategy

### Phase 1: Agent Infrastructure (Weeks 1-2)
- Create `BearCallSpreadAgent` as Level 3 Strategy Execution Agent
- Implement core Bear Call Spread logic (strike selection, wing width calculation)
- Integrate with `Portfolio Orchestrator Agent` for delegation
- Create agent communication patterns (async request/response)

### Phase 2: Workflow Implementation (Week 3)
- Update `docs/agents_workflows/bearish_strategy_workflow.md` with detailed logic
- Implement resistance-based strike selection algorithm
- Create risk/reward optimization for wing width selection
- Add profit target and stop-loss calculations specific to Bear Call Spread

### Phase 3: Configuration and Testing (Week 4)
- Create `config/strategies/bear_call_spread.yaml` configuration file
- Define strategy parameters (max strikes, min credit, wing width ranges)
- Integration testing with `Stock Selection Agent` and `Risk Management Agent`
- Backtest Bear Call Spread strategy against historical bearish candidates

### Phase 4: Production Integration (Week 5)
- Update `Portfolio Orchestrator Agent` delegation logic for bearish bias
- Implement monitoring and alerting for Bear Call Spread positions
- Create operational runbook for Bear Call Spread management
- Production deployment with limited position sizing

## Risk Assessment

| Risk | Severity | Likelihood | Impact | Mitigation |
|------|----------|------------|--------|------------|
| Unlimited theoretical risk on naked call side | Critical | Low | Account blow-up | Use spread structure (long call cap), strict position sizing per ADR-008 |
| Assignment risk on short call | High | Medium | Forced short stock position | Monitor ITM probability, close/roll before expiration, maintain assignment capacity |
| Rapid upside move breaching short strike | High | Medium | Max loss realization | Dynamic strike selection based on resistance, stop-loss at 2× credit received |
| Incorrect bearish bias identification | Medium | Medium | Losing trades | Ensemble model validation, sentiment veto check, technical confirmation required |
| Insufficient premium collection | Low | Low | Poor risk/reward ratio | Minimum credit threshold (e.g., $0.50/spread), reject low-premium setups |
| Over-concentration in bearish positions | High | Low | Portfolio correlation spike | Correlation matrix check per ADR-005, limit bearish exposure to 30% of portfolio heat |
| Agent logic errors in multi-leg execution | Medium | Low | Incorrect order submission | Comprehensive testing, order preview validation, manual approval mode for first 10 trades |

## Monitoring and Success Criteria

### Key Metrics

1. **Bear Call Spread Success Rate**: Target 65-75% profitable trades
   - Metric: `(Profitable BCS trades / Total BCS trades) × 100`
   - Alerting: <60% success rate over 20-trade rolling window

2. **Premium Collection Rate**: Target $200-400 per trade
   - Metric: `Average credit received per Bear Call Spread`
   - Alerting: <$150 average premium over 10-trade window

3. **Assignment Rate**: Target <10% early assignment
   - Metric: `(Assigned BCS positions / Total BCS positions) × 100`
   - Alerting: >15% assignment rate

4. **Max Loss Realization**: Target <5% trades reaching max loss
   - Metric: `(Max loss trades / Total BCS trades) × 100`
   - Alerting: >8% max loss rate

5. **Average Days to Close**: Target 21-28 days (before expiration)
   - Metric: `Average holding period for closed BCS positions`
   - Alerting: >35 days average (indicates holding too long)

### Alerting Thresholds

- **BearCallSpreadAgent Error**: Agent crash or unhandled exception
- **Order Execution Failure**: >5% order rejection rate
- **Strike Selection Error**: Selected strike outside valid range
- **Risk Limit Breach**: Position size exceeds `max_portfolio_heat` allowance
- **Correlation Spike**: Bearish positions correlated >0.8 with existing portfolio

### Success Criteria

- **Functional**: BearCallSpreadAgent successfully executes 10 consecutive trades without manual intervention
- **Performance**: Bear Call Spread strategy achieves 70%+ win rate over first 30 trades
- **Business Impact**: Adds $12,000+ annual premium income within first year
- **Risk Management**: Zero unauthorized risk limit breaches, all positions respect ADR-008 parameters

## Consequences

-   **Implementation**: A new `BearCallSpreadAgent` will be created as a Level 3 `Strategy Execution Agent`.
-   **Workflow**: The `docs/agents_workflows/bearish_strategy_workflow.md` document will be updated to detail the specific logic for the Bear Call Spread (strike selection based on resistance, wing width based on risk/reward, etc.).
-   **Configuration**: The strategy's parameters will be managed in the `config/strategies/bear_call_spread.yaml` file, as defined in the system's configuration management plan.
-   **Orchestrator Logic**: The `Orchestrator` will be updated to delegate to the `BearCallSpreadAgent` when it receives a candidate with a "Bearish" bias.
-   **Strategy Completeness**: System now covers all market biases (Neutral: Iron Condor, Bullish: Cash-Secured Put, Bearish: Bear Call Spread)
-   **Portfolio Diversification**: Enables profit generation in bearish market conditions, reducing dependency on neutral/bullish setups
-   **Risk Framework**: Extends existing risk management patterns to bearish strategies, maintains defined-risk principle
