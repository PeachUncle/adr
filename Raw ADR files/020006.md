# ADR-002: Mobile-First Responsive Strategy with Sheet Navigation

## Status

Accepted

## Context

The existing chat UI has a fixed sidebar that doesn't work well on mobile devices. Users need to access channel navigation on all screen sizes, but mobile screens don't have space for a persistent sidebar.

## Decision

We will implement a mobile-first responsive design using Shadcn Sheet component for mobile navigation and a fixed sidebar for desktop.

## Rationale

### Chosen: Mobile-First with Sheet

- **Mobile Experience**: Sheet slides in from left, doesn't block content
- **Desktop Experience**: Fixed sidebar at 256px width
- **Breakpoint**: 768px (Tailwind's `md:` breakpoint)
- **Navigation**: Hamburger menu (Menu icon) triggers Sheet on mobile
- **State Management**: Sheet closes automatically when user selects channel

### Rejected Alternatives

**Responsive Sidebar (Collapsible)**

- ❌ Complex animation states
- ❌ Content jumping when sidebar toggles
- ❌ Harder to implement with Shadcn components

**Bottom Navigation (Mobile)**

- ❌ Doesn't fit chat app mental model
- ❌ Limited space for channel list
- ❌ Inconsistent with desktop experience

**Drawer Component**

- ❌ Shadcn doesn't provide Drawer (Sheet is the equivalent)
- ❌ Would require custom implementation

**Always-Hidden Sidebar**

- ❌ Poor desktop experience (wasted screen space)
- ❌ Extra clicks required on desktop

## Implementation Updates

### Original Implementation (2024)
Used Sheet component for mobile navigation with hamburger menu trigger.

### Current Implementation (2025)
Extended by [ADR-015: Unified Sidebar Navigation](./adr-015-unified-sidebar-navigation.md) to use Shadcn sidebar-07 component:

**Mobile (<768px):**
```jsx
// Sidebar hidden by default, opens as overlay sheet
<SidebarProvider>
  <AppSidebar />
  <SidebarInset>
    <SidebarTrigger /> {/* Hamburger menu */}
  </SidebarInset>
</SidebarProvider>
```

**Desktop (≥768px):**
```jsx
// Sidebar visible by default, toggles expanded/icon-only
<SidebarProvider>
  <AppSidebar /> {/* Collapsible sidebar */}
  <SidebarInset>
    <SidebarTrigger /> {/* Toggle button */}
  </SidebarInset>
</SidebarProvider>
```

**Key Principles Maintained:**
- ✅ Mobile-first responsive design
- ✅ Sheet/overlay pattern for mobile
- ✅ Persistent navigation for desktop
- ✅ 768px breakpoint (Tailwind `md:`)

**What Changed:**
- Unified sidebar component replaces dual mobile/desktop navigation
- Shadcn handles responsive logic automatically
- No custom breakpoint logic needed

## Implementation Details

### Mobile (<768px)

```jsx
// Hamburger button
<Button className="md:hidden absolute top-4 left-4 z-50">
  <Menu />
</Button>

// Sheet for navigation
<Sheet>
  <SheetTrigger>...</SheetTrigger>
  <SheetContent side="left" className="w-[280px] p-0">
    <ChannelListHeader />
    <ChannelList />
    <UserFooter />
  </SheetContent>
</Sheet>
```

### Desktop (≥768px)

```jsx
// Fixed sidebar
<aside className="hidden md:flex md:w-64 flex-col border-r">
  <ChannelListHeader />
  <ChannelList />
  <UserFooter />
</aside>
```

## Consequences

### Positive

- Excellent mobile experience with native-feeling slide-out navigation
- Desktop users get persistent channel list (no extra clicks)
- Sheet component handles focus trapping and accessibility automatically
- Consistent with modern chat app patterns (Discord, Slack mobile)

### Negative

- Slightly more complex state management (Sheet open/close)
- Mobile users need extra tap to access channels
- Different interaction patterns between mobile/desktop

### Accessibility Benefits

- Sheet traps focus when open (keyboard users can't tab outside)
- Escape key closes Sheet
- Proper ARIA labels and roles
- Touch targets meet 44px minimum requirement

## Performance Impact

- Sheet content only renders when opened (lazy loading)
- No impact on desktop (Sheet not rendered)
- Minimal JavaScript for state management

## Testing Strategy

- Manual testing on actual mobile devices
- Verify Sheet closes on channel selection
- Test keyboard navigation (Tab, Escape)
- Verify touch targets are ≥44px
