# ADR-0002: Initial Segmentation Strategy

Status: Accepted  
Date: 2025-09-14  
Supersedes: None  
Related: ADR-0001 (Stack), planned ADR-0003 (Orientation Scoring)

## Context

We need to partition meshes into logical color/material regions or printable sub-parts. Early milestones require a pragmatic, deterministic approach that is:

- Fast for meshes <= ~150k faces.
- Deterministic with a seed.
- Capable of leveraging geometric cues (curvature, connected components) without heavy ML.

Future phases may integrate semantic or texture-driven segmentation, but current scope is strictly geometry-based.

## Options Considered

1. Pure connected components (weak: ignores curvature detail).
2. Region growing by mean curvature similarity (stable, tunable tolerance).
3. K-means on per-face feature vectors (normals, curvature, position) (may cluster discontiguous regions).
4. Spectral clustering of mesh Laplacian (higher quality but slower and less deterministic).
5. Hybrid: connected component pre-pass + curvature-driven refinement (balanced complexity).

## Decision

Adopt a hybrid pipeline:

1. Compute connected components to split disjoint shells.
2. For each component above a face threshold, compute per-face principal curvature magnitude (approx via angle deviation / normal variance in 1-ring).
3. Perform curvature-constrained region growing starting from seed faces chosen via k-means++ over curvature histogram bins (deterministic via seeded RNG).
4. Optional k-means (low k) refinement on region feature centroids (average normal, curvature mean) to merge over-segmented patches.

This balances speed and perceptual grouping without full spectral solves.

## Rationale

- Determinism: Seeding ensures reproducibility for caching and color palette reuse.
- Performance: All operations are O(F log F) or better (sorting & neighborhood lookups); no large eigendecompositions.
- Extensibility: Can later swap curvature estimator or plug semantic priors without invalidating interfaces.

## Consequences

- Thin high-curvature ridges may fragment more than desired (acceptable trade-off now).
- Texture / color boundaries not explicitly considered yet.
- Over-segmentation risk mitigated by refinement merge step.

## Metrics / Acceptance

- Target runtime: <3s on 150k-face mesh (M-series CPU) for segmentation stage.
- Deterministic region count stable under repeated runs with same params.
- Mean intra-segment normal variance significantly lower than global variance (add test later).

## Future Work

- Integrate texture edge weighting when UVs present.
- Add semantic label fusion option (external classifier) behind a flag.
- Evaluate fast Laplacian spectral embedding if performance headroom permits.
