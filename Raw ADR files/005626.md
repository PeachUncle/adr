# ADR-0003: Data Contract Validation and Silent Failure Prevention

**Status**: ACCEPTED
**Date**: 2025-10-31
**Context**: Step 14.20 bug where script skipped all experiments due to field name mismatch (`id` vs `experiment_id`)

## Problem Statement

The regeneration script silently failed when loading experiments from `experiments/index.json` because:
1. **Field name changed** in index.json from `id` to `experiment_id` (during reorganization)
2. **Script was NOT updated** to match
3. **No validation** of the schema - script just skipped records silently
4. **No test coverage** of the script's data loading logic

This is a **fail-silent** anti-pattern: the script appeared to work (exit code 0) but processed 0/15 experiments.

## Consequences of Fail-Silent

- ❌ 9 out of 15 config runs had no OOS results (0.00 scores on UI)
- ❌ Users had no indication of what was wrong
- ❌ No error logs to debug from
- ❌ Problem invisible until user manually checked the system
- ❌ Time wasted on audit process that could have been prevented

## Decision

Adopt **fail-loud, validate-early** approach for all data contract boundaries:

### 1. Schema Validation at Entry Points
- All scripts loading JSON should validate schema immediately
- Log and fail if required fields missing
- Include field names in error message

### 2. Contract Documentation
- Document all JSON schemas in `docs/DATA_CONTRACTS.md`
- Include version, required fields, examples
- Link from code that uses the schema

### 3. Test Coverage
- Add unit tests for data loading functions
- Test both success and failure cases
- Verify schema changes are caught by tests

### 4. Code Review Checklist
- When changing JSON structure: update scripts + tests + docs
- When changing field names: search for all usages
- When adding new endpoints: document request/response schemas

## Implementation

### Pattern 1: Fail-Loud Data Loading
```python
import json
from pathlib import Path
from typing import List, Dict, Any

def load_experiments_index(index_path: Path) -> List[Dict[str, Any]]:
    """Load and validate experiments index.

    Required schema:
    [
      {
        "experiment_id": str,  # REQUIRED
        "name": str,           # OPTIONAL
      },
      ...
    ]
    """
    if not index_path.exists():
        raise FileNotFoundError(f"Index not found: {index_path}")

    try:
        with open(index_path) as f:
            records = json.load(f)
    except json.JSONDecodeError as e:
        raise ValueError(f"Invalid JSON in {index_path}: {e}")

    if not isinstance(records, list):
        raise ValueError(f"Expected list, got {type(records)}")

    # Validate each record
    required_fields = ["experiment_id"]
    for i, record in enumerate(records):
        if not isinstance(record, dict):
            raise ValueError(f"Record {i} is not a dict: {record}")

        missing_fields = [f for f in required_fields if f not in record]
        if missing_fields:
            raise ValueError(
                f"Record {i} missing required fields: {missing_fields}\n"
                f"Record: {record}\n"
                f"Expected fields: {required_fields}"
            )

    return records
```

### Pattern 3: Test Coverage for Data Loading
```python
# tests/test_experiments_loading.py

import json
import pytest
from pathlib import Path
from scripts.regenerate_all_backtests import load_experiments_index

def test_load_experiments_index_valid(tmp_path):
    """Valid index should load successfully."""
    index_file = tmp_path / "index.json"
    index_file.write_text(json.dumps([
        {"experiment_id": "exp1", "name": "test1"},
        {"experiment_id": "exp2"},
    ]))

    result = load_experiments_index(index_file)
    assert len(result) == 2
    assert result[0]["experiment_id"] == "exp1"

def test_load_experiments_index_missing_required_field(tmp_path):
    """Missing required field should raise ValueError."""
    index_file = tmp_path / "index.json"
    index_file.write_text(json.dumps([
        {"name": "test1"},  # Missing experiment_id
    ]))

    with pytest.raises(ValueError, match="missing required fields"):
        load_experiments_index(index_file)

def test_load_experiments_index_invalid_json(tmp_path):
    """Invalid JSON should raise ValueError."""
    index_file = tmp_path / "index.json"
    index_file.write_text("{invalid json")

    with pytest.raises(ValueError, match="Invalid JSON"):
        load_experiments_index(index_file)

def test_load_experiments_index_not_list(tmp_path):
    """Non-list root should raise ValueError."""
    index_file = tmp_path / "index.json"
    index_file.write_text(json.dumps({"experiments": []}))

    with pytest.raises(ValueError, match="Expected list"):
        load_experiments_index(index_file)

def test_load_experiments_index_missing_file(tmp_path):
    """Missing file should raise FileNotFoundError."""
    with pytest.raises(FileNotFoundError):
        load_experiments_index(tmp_path / "nonexistent.json")
```

### Pattern 4: Code Review Checklist for Schema Changes
When modifying JSON files/schemas:

```
Data Contract Change Checklist:
- [ ] Updated all consumers of the data (scripts, routes, services)
- [ ] Added migration logic if breaking change (e.g., support both field names)
- [ ] Updated docs/DATA_CONTRACTS.md with new schema
- [ ] Added/updated tests for data loading
- [ ] Verified via grep that all usages updated:
      grep -r "\.get\(\"old_field_name\"\)" aimoto-backend/ scripts/
- [ ] Added changelog entry explaining the change
- [ ] If in production: added backwards compatibility layer
```

## Benefits

1. **Fail-Loud**: Errors immediately visible in logs, easy to debug
2. **Fast Feedback**: Issues caught in CI/testing, not production
3. **Documentation**: Data contracts explicit and discoverable
4. **Maintainability**: Schema changes tracked and validated
5. **Scalability**: Pattern applies to all data boundaries (API, files, DB)

## Example: How This Prevents the Bug

With these patterns:

**Old Code** (what broke):
```python
experiment_id = exp_record.get("id")  # Silent: returns None
if not experiment_id:
    logger.warning("Experiment record missing 'id' field, skipping")  # User never sees this
    continue  # Silent failure
```

**New Code** (with validation):
```python
# 1. Validate schema at entry point
records = load_experiments_index(index_path)  # Fails immediately with clear error

# 2. If needed, support migration:
experiment_id = record.get("experiment_id") or record.get("id")

# 3. Covered by tests
# test_load_experiments_index_missing_required_field would catch it

# 4. Documented in DATA_CONTRACTS.md
# Future devs know the schema and required fields
```

**Result**: Error caught immediately during development, not in production
