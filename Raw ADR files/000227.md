# ADR-001: Microservices Architecture with Spring Boot and AWS Lambda

## Status
Accepted

## Context
The Personal Vacation Optimizer requires a scalable, maintainable architecture that can handle both AI-driven vacation planning and user preference management efficiently. The system needs to integrate multiple technologies while maintaining cost-effectiveness for personal use.

## Decision
We will implement a hybrid microservices architecture combining:

1. **Spring Boot Microservice** for complex business logic (vacation preferences, optimization algorithms)
2. **AWS Lambda Functions** for event-driven operations (AI agent, MCP server, authentication)
3. **Gradio Web UI** for user interface with Firebase authentication

## Rationale

### Spring Boot Microservice Benefits:
- **Complex Algorithm Implementation**: Multi-criteria decision analysis for vacation optimization
- **Database Integration**: JPA/Hibernate for preference persistence with PostgreSQL
- **Enterprise Patterns**: Comprehensive testing, observability, and resilience patterns
- **API Standards**: RESTful APIs with OpenAPI documentation
- **Development Velocity**: Rich ecosystem and developer tooling

### AWS Lambda Benefits:
- **Cost Efficiency**: Pay-per-execution model ideal for personal projects
- **Scalability**: Automatic scaling for varying AI agent usage
- **Event-Driven**: Perfect for stateless operations like authorization
- **Integration**: Seamless AWS ecosystem integration

## Consequences

### Positive:
- **Separation of Concerns**: Each service has a clear responsibility
- **Technology Optimization**: Right tool for each job
- **Cost Effective**: Minimal infrastructure costs for personal use
- **Scalable**: Can handle growth in usage
- **Maintainable**: Clear boundaries and interfaces

### Negative:
- **Distributed System Complexity**: Network latency and failure handling
- **Operational Overhead**: Multiple deployment targets
- **Data Consistency**: Cross-service data synchronization challenges

### Mitigation Strategies:
- **Correlation IDs**: Distributed tracing across services
- **Circuit Breakers**: Resilience patterns in Spring Boot service
- **Graceful Degradation**: Fallback mechanisms in Lambda functions
- **Comprehensive Monitoring**: Observability at all levels

## Implementation Details

### Communication Patterns:
- **Synchronous**: REST APIs for user-initiated operations
- **Asynchronous**: Event-driven for background processing
- **Authentication**: Firebase JWT tokens across all services

### Data Management:
- **Single Source of Truth**: PostgreSQL for persistent data
- **Caching**: In-memory caching for frequently accessed preferences
- **Consistency**: Eventual consistency with compensation patterns

### Deployment Strategy:
- **Spring Boot**: Render.com for free tier hosting
- **Lambda Functions**: AWS with Terraform infrastructure as code
- **Database**: Render PostgreSQL free tier
