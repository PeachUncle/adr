# Decision: Three-Pass Human-Style Editing System

Date: 2025-11-02

## Context

The initial pipeline attempted to do everything in a single LLM pass: understand the story, select clips, handle length constraints, and ensure quality. This resulted in compromised outputs because the LLM had to simultaneously optimize for too many competing goals.

A better approach was needed that mirrors how human video editors actually work: understand the story first, rough cut second, polish third.

## Options Considered

- **Option A: Single-Pass LLM**
  - One LLM call handles narrative + timing + length constraints
  - Pros: Simple, fast, fewer API calls
  - Cons: Compromised quality, conflicting objectives, hard to debug, no separation of concerns

- **Option B: Two-Pass System**
  - Pass 1: LLM for story selection
  - Pass 2: Deterministic assembly and polish
  - Pros: Simpler than three-pass, reduced LLM cost
  - Cons: Still mixing narrative and timing concerns in Pass 1

- **Option C: Three-Pass System (Human-Style)**
  - Pass 1: Story Understanding (LLM = "editor's brain")
  - Pass 2: Rough Cut Assembly (LLM + deterministic)
  - Pass 3: Finishing (deterministic only)
  - Pros: Clear separation of concerns, matches human workflow, quality at each stage
  - Cons: More complexity, additional processing time

## Decision

Chose **Option C (Three-Pass System)**.

**Pass 1 — Story Understanding (LLM):**
- Input: Full transcript + light per-phrase metadata
- Goal: Understand what the clip is about and what story can be told
- Process:
  - Feed entire transcript once
  - Identify central theme, emotional arc, memorable moments
  - Mark potential hooks (high emotion/tension/curiosity)
  - Mark cuttable fluff or redundancies
- Output: Storyboard with narrative blueprint (roles and order)
  ```json
  {
    "outline": ["hook", "setup", "build", "climax", "wrap"],
    "phrases": [
      {"id":"p04","role":"hook"},
      {"id":"p11","role":"build"},
      {"id":"p17","role":"climax"},
      {"id":"p23","role":"wrap"}
    ]
  }
  ```

**Pass 2 — Rough Cut Assembly (LLM + deterministic):**
- Goal: Piece together story into coherent 60-90s rough cut
- Steps:
  1. For each chosen phrase, fetch actual audio/text ranges
  2. LLM (or small model) refines timing suggestions
  3. Trim filler, pauses, repeated phrases
  4. Ensure natural transitions
  5. Deterministic rules finalize times (no mid-word cuts, safe crossfades)
- Output: Timestamped rough cut
  ```json
  [
    {"start":12.3,"end":15.8,"role":"hook"},
    {"start":24.1,"end":28.5,"role":"build"},
    {"start":46.2,"end":51.7,"role":"climax"},
    {"start":63.0,"end":66.5,"role":"wrap"}
  ]
  ```

**Pass 3 — Finishing (deterministic only):**
- Goal: Polish (no LLM needed)
- Steps:
  1. Fine-trim word boundaries
  2. Add transitions, zooms, effects, captions
  3. Normalize loudness, balance pacing
  4. Validate visual continuity and speech clarity
- Output: Publish-ready short

## Consequences

**Positive:**
- Clear separation of concerns (understand → assemble → polish)
- Matches intuitive human editing workflow
- Easier to debug (can inspect output at each stage)
- Can optimize each pass independently
- Creativity (LLM narrative) + control (deterministic refinement)
- No token waste (right tool for each job)

**Negative:**
- More processing steps (potentially longer total time)
- More code to maintain (three distinct stages)
- Requires careful data passing between stages

**Affected Areas:**
- Storyboard generation (now Pass 1)
- Timeline assembly (now Pass 2)
- Final rendering (now Pass 3)
- API endpoints (may need progress tracking for three stages)
- Error handling (failures can occur at any of three stages)

**Implementation mapping:**
| Stage | Who | Input | Output | Purpose |
|-------|-----|-------|--------|---------|
| 1. Story Understanding | LLM-large | Full transcript (summaries) | Storyboard | Narrative direction |
| 2. Rough Cut | LLM-small + heuristics | Chosen phrases | Timestamps list | Coherent flow |
| 3. Finishing | Deterministic | Timestamp list | Rendered short | Final polish |
