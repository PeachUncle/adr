# ADR-0005: Texture-Aware Mesh Remeshing

**Status:** Accepted
**Date:** 2024-12-19
**Deciders:** 3D Mesh Processing Team

## Context

The BidPal 3D toolchain requires intelligent mesh remeshing capabilities that consider texture information to preserve visual quality during optimization. Traditional geometric remeshing often destroys texture detail by not considering where textures have high-frequency content that should be preserved through denser mesh sampling.

### Problem Statement

1. **Geometric-only remeshing** loses visual fidelity in textured areas with high detail
2. **Fixed-density remeshing** wastes vertices in uniform texture regions
3. **Manual adjustment** is impractical for batch processing workflows
4. **Lack of texture-mesh integration** prevents effective automated optimization

### Requirements

- Detect texture edges and high-frequency content automatically
- Guide mesh density based on texture complexity
- Preserve manifold topology during cutting and remeshing
- Support standard texture formats (PNG, JPEG) and mesh formats (OBJ, 3MF)
- Integrate with existing color quantization pipeline
- Provide deterministic results for reproducible processing

## Decision

We implement a four-stage texture-aware remeshing pipeline:

### 1. Texture Edge Detection (`core/texture/edge_detect.py`)

**Algorithm:** Hybrid Canny + Sobel edge detection with perceptual weighting

**Key Decisions:**

- **Canny edge detection** for clean, thin edges with hysteresis thresholding
- **Sobel operators** for gradient-based edge strength measurement  
- **Gaussian preprocessing** (σ=1.0) to reduce noise while preserving features
- **LAB color space conversion** for perceptually uniform edge detection
- **Contour extraction** using OpenCV findContours with RETR_EXTERNAL mode
- **Douglas-Peucker simplification** to reduce vertex count while preserving shape

**API Design:**

```python
@dataclass
class EdgeDetectionResult:
    edge_map: np.ndarray        # Binary edge mask
    contours: List[np.ndarray]  # Extracted contour polylines  
    edge_strength: np.ndarray   # Gradient magnitude map
    processing_stats: dict      # Timing and parameter info
```

**Rejected Alternatives:**

- **Pure Sobel:** Produces thick, noisy edges
- **Laplacian of Gaussian:** More noise-sensitive than Canny
- **Deep learning methods:** Too complex, require training data

### 2. Contour Projection (`core/geom/contour_project.py`)

**Algorithm:** UV-to-surface projection with barycentric interpolation

**Key Decisions:**

- **Face-UV intersection testing** using point-in-triangle tests
- **Barycentric coordinate interpolation** for accurate surface mapping
- **Multi-contour support** with per-contour error tracking
- **Tolerance-based matching** (1e-6) for floating-point robustness
- **Intersection statistics** for quality assessment

**API Design:**

```python
@dataclass  
class ProjectedContour:
    world_points: np.ndarray       # (N, 3) 3D coordinates
    face_indices: np.ndarray       # (N,) face assignments
    barycentric_coords: np.ndarray # (N, 3) interpolation weights
    uv_points: np.ndarray         # (N, 2) original UV coords
    segment_lengths: np.ndarray   # (N-1,) world-space distances
```

**Rejected Alternatives:**

- **Nearest neighbor projection:** Inaccurate at face boundaries
- **Ray casting:** Overkill for UV-mapped meshes, slower
- **Grid-based sampling:** Loses contour topology information

### 3. Mesh Cutting (`core/geom/mesh_cut.py`)

**Algorithm:** Topologically-aware edge insertion with face splitting

**Key Decisions:**

- **Edge insertion** along projected contours to create cut lines
- **Face subdivision** using barycentric coordinates for new vertices
- **Vertex color interpolation** to preserve texture information
- **Manifold preservation** through careful vertex sharing
- **Multi-contour handling** with intersection resolution

**API Design:**

```python
@dataclass
class MeshCutResult:
    vertices: np.ndarray      # Enhanced vertex array
    faces: np.ndarray        # Modified face connectivity
    vertex_colors: Optional[np.ndarray]  # Interpolated colors
    cut_edges: List[np.ndarray]         # Generated cut topology
    topology_stats: dict                # Validation metrics
```

**Rejected Alternatives:**

- **Boolean operations:** Too slow, often produces non-manifold results
- **Voxel-based cutting:** Loses surface detail and smoothness
- **Delaunay re-triangulation:** Difficult to preserve UV consistency

### 4. Poisson-Guided Remeshing (`core/remesh/poisson_guided.py`)

**Algorithm:** Adaptive Poisson disk sampling with texture density guidance

**Key Decisions:**

- **Texture density function** computed from edge detection results
- **Adaptive Poisson sampling** with texture-weighted density control
- **Multiple reconstruction methods:** Ball Pivoting, Poisson, Alpha Shapes
- **Open3D integration** for robust surface reconstruction
- **Density scaling parameters** for user control over detail preservation

**API Design:**

```python
@dataclass
class PoissonRemeshResult:
    vertices: np.ndarray          # Resampled vertex positions
    faces: np.ndarray            # New triangulation
    vertex_colors: Optional[np.ndarray]  # Transferred colors
    sample_density: np.ndarray   # Achieved sampling density
    reconstruction_stats: dict   # Quality metrics
```

**Rejected Alternatives:**

- **Uniform Poisson sampling:** Ignores texture content variation
- **CVT-based methods:** More complex, similar quality results
- **Learning-based sampling:** Requires training data, less controllable

## Implementation Architecture

### Dependencies

**Required:**

- `numpy` - Core numerical operations
- `scipy` - Spatial data structures, interpolation
- `scikit-image` - Canny/Sobel edge detection
- `opencv-python` - Contour extraction and processing
- `open3d` - Surface reconstruction algorithms

**Optional:**

- `shapely` - Topology-preserving contour simplification
- `trimesh` - Additional mesh processing utilities

### Error Handling Strategy

- **Graceful degradation:** Missing optional dependencies skip advanced features
- **Input validation:** Early parameter checking with clear error messages  
- **Robust defaults:** Fallback parameters when automatic estimation fails
- **Progressive quality:** Multiple reconstruction methods as fallbacks

### Performance Considerations

- **Lazy imports:** Optional dependencies loaded only when needed
- **Memory efficiency:** Process texture tiles for large images
- **Computational complexity:** O(n log n) for most operations
- **Parallel potential:** Edge detection and sampling are parallelizable

## Consequences

### Positive

✅ **Texture-aware optimization:** Mesh density adapts to visual content importance  
✅ **Automated workflow:** No manual adjustment needed for most use cases  
✅ **High quality preservation:** Edge-guided sampling maintains visual fidelity  
✅ **Robust implementation:** Comprehensive error handling and fallbacks  
✅ **Modular design:** Each stage can be used independently or combined  
✅ **Extensible architecture:** Easy to add new edge detection or reconstruction methods  

### Negative

⚠️ **Complex dependency chain:** Requires multiple specialized libraries  
⚠️ **Performance overhead:** More computation than simple geometric remeshing  
⚠️ **Memory requirements:** Stores texture data, edge maps, and intermediate results  
⚠️ **Parameter sensitivity:** Quality depends on threshold tuning for edge detection  

### Mitigation Strategies

- **Dependency management:** Optional imports with graceful degradation
- **Performance optimization:** Texture tiling for large images, parallel processing potential
- **Memory optimization:** Stream processing for large meshes, garbage collection hints
- **Parameter automation:** Adaptive threshold estimation based on image statistics

## Usage Examples

### Basic Texture-Guided Remeshing

```python
from core.texture.edge_detect import detect_texture_edges
from core.geom.contour_project import project_contours_to_surface  
from core.geom.mesh_cut import cut_mesh_along_contours
from core.remesh.poisson_guided import poisson_guided_remesh

# 1. Detect texture edges
edge_result = detect_texture_edges(texture, method='canny')

# 2. Project contours to mesh surface
projection_result = project_contours_to_surface(
    contours=edge_result.contours,
    vertices=vertices, 
    faces=faces,
    uv_coords=uv_coords
)

# 3. Cut mesh along projected contours
cut_result = cut_mesh_along_contours(
    vertices, faces, 
    projected_contours=projection_result.projected_contours
)

# 4. Remesh with texture-guided density
remesh_result = poisson_guided_remesh(
    cut_result.vertices,
    cut_result.faces, 
    uv_coords,
    texture,
    target_vertices=1000
)
```

### Integration with Color Quantization

```python
# Combined workflow: color quantization + texture remeshing
from tools.colorbake.bake import bake_vertex_colors
from core.texture.edge_detect import detect_texture_edges

# 1. Quantize colors first
quantized_result = bake_vertex_colors(
    mesh, texture, palette_size=8
)

# 2. Use quantized texture for edge detection  
edge_result = detect_texture_edges(
    quantized_result.quantized_texture, 
    method='combined'
)

# 3. Remesh with quantized color guidance
remesh_result = texture_guided_remesh(
    mesh, quantized_result.quantized_texture, 
    edge_result.contours
)
```
