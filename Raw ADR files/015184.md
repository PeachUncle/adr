# ADR-001: Use Litestar as ASGI Framework

## Status
Accepted

## Context

We need a modern, high-performance Python web framework for building the backend API. Key requirements:

- **Performance**: Handle high request volumes with low latency
- **Type Safety**: Full typing support with Pydantic integration
- **OpenAPI**: Auto-generate OpenAPI/Swagger documentation
- **Async**: Native async/await support
- **Middleware**: Flexible middleware system
- **Modern**: Active development, good documentation
- **Production-Ready**: Battle-tested, stable

### Alternatives Considered

1. **FastAPI**: Popular, but built on Starlette (extra layer)
2. **Django**: Mature but heavy, primarily synchronous
3. **Flask**: Simple but lacks modern async features
4. **Starlette**: Low-level, requires more boilerplate
5. **Litestar**: Modern ASGI framework with excellent typing

## Decision

We will use **Litestar 2.0+** as our ASGI framework.

### Rationale

- **Performance**: Built on top of ASGI, excellent benchmarks
- **Type Safety**: Best-in-class Pydantic v2 integration
- **OpenAPI**: Automatic schema generation from type hints
- **Developer Experience**: Clean API, excellent documentation
- **Dependency Injection**: Built-in DI system
- **Middleware**: Rich middleware ecosystem (CORS, rate limiting, Prometheus)
- **Testing**: First-class test client support
- **Community**: Growing community, active development

### Key Features Used

```python
from litestar import Litestar, Controller, get, post
from litestar.contrib.prometheus import PrometheusConfig

class HealthController(Controller):
    path = ""
    
    @get("/healthz")
    async def health_check(self) -> dict:
        return {"status": "healthy"}

app = Litestar(
    route_handlers=[HealthController],
    openapi_config=OpenAPIConfig(...),
    lifespan=[lifespan],
)
```

## Consequences

### Positive

- ✅ High performance with async support
- ✅ Excellent type safety and IDE support
- ✅ Auto-generated OpenAPI documentation
- ✅ Clean, modern API design
- ✅ Built-in support for Prometheus, CORS, rate limiting
- ✅ Easy testing with `AsyncClient`
- ✅ Active community and good documentation

### Negative

- ⚠️ Smaller community compared to FastAPI/Django
- ⚠️ Fewer third-party plugins (but growing)
- ⚠️ Some team members may need to learn the framework

### Mitigations

- Framework is well-documented with examples
- Active Discord community for support
- Clear migration path if needed (ASGI standard)
- Team training session planned
