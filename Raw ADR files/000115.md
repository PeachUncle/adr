# ADR-0002: Sampling Modes & Palette Index Smoothing

Status: Accepted  
Date: 2025-09-13  
Supersedes: None  
Related: ADR-0001-3mf-strategy

## Context

Early color baking used a single bilinear sampling path producing softened edges for stylized / flat-shaded textures. For multi-color filament printing (limited discrete palette) blurring across hard texture boundaries reduces edge fidelity and introduces mixed colors that later quantization must approximate.

We also observed isolated “pepper” speckles after quantization—single vertices adopting a palette entry different from all immediate neighbors—especially with noisy UVs or aggressive palette reduction.

## Decision

Introduce multiple texture sampling modes plus a post-quantization smoothing pass:

### Sampling Modes

| Mode | Intent | Mechanism |
|------|--------|-----------|
| `nearest` | Max edge sharpness / pixel art | Direct texel lookup (UV clamped) |
| `bilinear` | Smooth gradients (legacy default) | Bilinear interpolation |
| `edge` | Hybrid: keep crisp edges without losing smooth regions | Compute local 3×3 channel max difference; if > threshold use nearest else bilinear |
| `supersample` | Anti-alias for minified textures | Uniform N×N grid of bilinear samples averaged (deterministic pattern) |

Deterministic seed influences only clustering; sampling itself is purely positional.

### Fixed Palette

`--fixed-palette` bypasses k-means and maps sampled vertex colors to provided palette using selected ΔE metric. This guarantees exact filament slot mapping and reproducibility across runs.

### Smoothing

`smooth_indices` performs iterative majority voting over vertex adjacency derived from face topology. A vertex changes to the palette index that is most frequent among its 1-ring neighbors if (a) that label count exceeds current label count and (b) (when preserve_contrast=True) the ΔE between labels is below a contrast threshold (currently 12 CIEDE2000 units).

Iterations stop early if no changes occur in a pass. Metadata records `smoothed_vertices` count (unique vertices changed at least once).

## Rationale

- Providing discrete modes avoids forcing users to trade crispness for gradient quality globally.
- Hybrid edge mode reduces manual switching and serves common stylized texture cases.
- Supersampling allows improved stability when UV density << texture resolution without introducing full mipmapping complexity.
- Fixed palette is essential for workflows driven by predefined AMS filament colors.
- Smoothing reduces visual salt-and-pepper artifacts that waste palette slots without losing meaningful boundaries.

## Alternatives Considered

1. Single adaptive algorithm (e.g., gradient-based continuous blend factor) — higher implementation complexity, harder to reason about determinism.
2. Mipmapping pyramid + level selection — overkill for current printing use-case and adds IO/computation overhead.
3. Graph cut / energy minimization for label smoothing — potentially higher quality but significantly more complex and slower; reserved for future milestone if needed.

## Consequences

- CLI surface area increases; documented defaults chosen to preserve original behavior (`bilinear`).
- Slight runtime overhead in edge + supersample modes; acceptable trade-off (profile later if >10% bake time).
- Smoothing can mask genuine small color details; default iterations=0 to keep opt-in.

## Implementation Notes

- Edge threshold presently channel max difference in sRGB (0..1). Could evolve to LAB ΔE.
- Contrast preservation uses LAB ΔE2000; threshold constant factored for future config.
- Supersampling grid uses deterministic offsets for stable hashing if later incorporated into cache keys.
- Mean/max ΔE post-smoothing are not recomputed (documented limitation); revisit if downstream consumers require smoothed accuracy metrics.

## Future Work

- Expose edge threshold and contrast delta as explicit CLI tunables.
- Cache vertex sampling results keyed by (UV hash, sampling mode, texture hash) for large meshes.
- Add optional ΔE recomputation after smoothing and/or histogram output.
- Evaluate lightweight energy minimization for complex noise patterns.
