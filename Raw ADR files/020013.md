# ADR-015: Unified Sidebar Navigation

## Status

Accepted

## Context

The application previously used a hybrid navigation strategy (ADR-013) with bottom tabs for mobile context switching and a fixed sidebar for desktop. This created several issues:

1. **Dual Navigation Patterns**: Mobile used bottom tabs + sheets, desktop used fixed sidebar
2. **Code Complexity**: 330 lines across MobileTabBar (150) + ChatLayout (180)
3. **State Management**: Complex context switching with localStorage persistence
4. **Inconsistent UX**: Different interaction patterns between mobile and desktop
5. **Limited Desktop Features**: Fixed sidebar couldn't collapse to icon-only mode

Shadcn released sidebar-07 component providing:
- Unified responsive sidebar for mobile and desktop
- Automatic collapsible behavior (expanded/icon-only on desktop)
- Overlay sheet behavior on mobile
- Built-in state persistence via localStorage
- No custom breakpoint logic required

## Decision

We will replace the bottom tab bar navigation with Shadcn's unified sidebar component that adapts responsively across all screen sizes.

### Architecture

```
Single Sidebar Component
├── Mobile (<768px): Hidden by default, opens as overlay sheet
├── Desktop (≥768px): Visible by default, toggles expanded/icon-only
└── Content Sections:
    ├── Workspace Header (name + owner settings)
    ├── Channels (with new channel button)
    ├── Documents (placeholder)
    ├── AI Agents (placeholder)
    └── User Footer (profile dropdown)
```

### Implementation

```jsx
// Unified layout for all screen sizes
<SidebarProvider>
  <AppSidebar
    channels={channels}
    activeChannelId={activeChannelId}
    onChannelSelect={onChannelSelect}
    onNewChannel={onNewChannel}
    user={user}
    isOwner={isOwner}
    onLogout={onLogout}
    workspaceName={workspaceName}
  />
  <SidebarInset>
    <header>
      <SidebarTrigger /> {/* Hamburger on mobile, toggle on desktop */}
    </header>
    <main>{children}</main>
  </SidebarInset>
</SidebarProvider>
```

## Rationale

### Chosen: Unified Sidebar (Shadcn sidebar-07)

**Benefits:**
- ✅ **Simpler Mental Model**: One navigation pattern for all devices
- ✅ **45% Code Reduction**: 330 lines → 180 lines
- ✅ **Better Desktop UX**: Collapsible sidebar (expanded/icon-only modes)
- ✅ **Automatic Responsive**: Shadcn handles mobile/desktop logic
- ✅ **No State Management**: No context switching, no localStorage logic
- ✅ **Consistent Behavior**: Same interaction pattern across devices
- ✅ **Built-in Accessibility**: Keyboard navigation, ARIA labels, focus management

**Mobile Behavior (<768px):**
- Sidebar hidden by default
- SidebarTrigger shows hamburger icon
- Tap hamburger → sidebar slides in as overlay sheet
- Select channel → sidebar auto-closes
- No bottom tab bar taking up screen space

**Desktop Behavior (≥768px):**
- Sidebar visible by default
- SidebarTrigger toggles expanded ↔ icon-only
- Select channel → sidebar stays visible
- User preference persists automatically
- More screen space for content when collapsed

### Rejected Alternatives

**Keep Bottom Tab Bar (Status Quo)**
- ❌ Dual navigation patterns to maintain
- ❌ Complex context switching state
- ❌ Bottom tabs waste mobile screen space (~60px)
- ❌ No collapsible option for desktop
- ❌ Custom responsive logic required

**Drawer Component**
- ❌ Shadcn doesn't provide Drawer (sidebar is the modern equivalent)
- ❌ Would require custom implementation
- ❌ Less feature-rich than sidebar-07

**Top Navigation Bar**
- ❌ Conflicts with page headers
- ❌ Harder to reach on mobile
- ❌ Doesn't scale well with many sections

## Consequences

### Positive

- **Simplified Codebase**: 45% reduction in navigation code
- **Unified UX**: Same navigation pattern on all devices
- **Better Desktop Experience**: Collapsible sidebar with icon-only mode
- **Automatic Responsive**: No custom breakpoint logic needed
- **Reduced State Complexity**: No context switching or persistence logic
- **More Mobile Screen Space**: No bottom tab bar
- **Built-in Features**: Tooltips, keyboard nav, accessibility handled by Shadcn

### Negative

- **Migration Effort**: 2.5 hours to migrate from bottom tabs
- **Breaking Change**: Deprecates ADR-013 implementation
- **Learning Curve**: Users familiar with bottom tabs need to adapt
- **Test Updates**: Mobile tab bar tests need rewriting

### Technical Implications

- **Deleted Components**: MobileTabBar (150 lines), ChannelListHeader
- **Deleted State**: activeContext, currentSheetContext, localStorage logic
- **New Dependencies**: @radix-ui/react-collapsible (via sidebar-07)
- **Simplified ChatLayout**: 180 lines → 80 lines
- **New AppSidebar**: 100 lines (replaces 150 from MobileTabBar)

## Migration Strategy

### Phase 1: DELETE
- Remove MobileTabBar component
- Remove ChannelListHeader component
- Clean up ChatLayout state and imports
- Break existing tests intentionally

### Phase 2: INSTALL
- Run `npx shadcn@latest add sidebar-07`
- Verify component installation

### Phase 3: BUILD
- Create AppSidebar with workspace navigation
- Rebuild ChatLayout with SidebarProvider
- Implement all features (channels, settings, user menu)

### Phase 4: VALIDATE
- Fix broken tests
- Test mobile and desktop responsive behavior
- Verify all functionality works

### Phase 5: DOCUMENT
- Update this ADR
- Deprecate ADR-013
- Update ADR-002 implementation notes

## Testing Strategy

### Responsive Behavior
- Mobile: Hamburger → sidebar opens → select channel → sidebar closes
- Desktop: Sidebar visible → toggle icon mode → stays visible
- Verify auto-close on mobile, stay-open on desktop

### Feature Validation
- Channel navigation and highlighting
- New channel creation button
- Owner-only Settings visibility
- User dropdown menu (Help, About, Settings, Logout)
- Real-time channel updates
- Workspace name display

### Cross-Device Testing
- iPhone SE (375px)
- iPad (768px)
- Desktop (1440px)

### Accessibility
- Keyboard navigation (Tab, Enter, Arrow keys)
- Screen reader announcements
- Touch targets ≥44px
- Focus indicators

## Performance Impact

### Bundle Size
- Net reduction: -50 lines of code
- New dependency: @radix-ui/react-collapsible (~15KB)
- Overall: Smaller bundle due to code reduction

### Runtime Performance
- Shadcn handles responsive logic (no custom breakpoints)
- localStorage managed by Shadcn (remove custom persistence)
- Single sidebar vs dual mobile/desktop navigation
- Faster initial render (simpler component tree)

## Rollback Plan

If sidebar-07 causes issues:

```bash
# Revert to MobileTabBar
git checkout components/MobileTabBar.jsx
git checkout components/ChatLayout.jsx
npm uninstall @radix-ui/react-collapsible

# Keep old code in archive/ for 2 weeks
```

Feature flag: `use_sidebar_v2`
- Gradual rollout: 10% → 50% → 100%
- Auto-rollback if >5% error rate
