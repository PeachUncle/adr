# ADR-0006: AMS Spool Mapping & Print Profile System

## Status: IMPLEMENTED ✅

Date: 2025-01-03

## Context

Building on the successful completion of multi-format input support (MILESTONE 4), the next strategic milestone focuses on bridging the gap between color quantization and actual 3D printing workflows. The 3D printing ecosystem requires automatic material selection, printer compatibility validation, and seamless integration with AMS (Automatic Material System) hardware.

## Decision

Implement a comprehensive AMS spool mapping and print profile system with the following components:

### 1. Perceptual Color Matching System

- **RGB to LAB color space conversion** for perceptual accuracy
- **Delta E 2000 color distance calculation** (industry standard for color difference)
- **Configurable color tolerance thresholds** for flexible matching

### 2. AMS Spool Database Architecture

- **SpoolColor**: RGB + LAB color representation with metadata
- **SpoolMaterial**: Material properties (type, density, temperature, printer compatibility)
- **Spool**: Complete spool with color + material + availability info
- **SpoolDatabase**: Search and matching capabilities with compatibility filtering

### 3. Enhanced Printer Profile System

- **Legacy Profile Support**: Backward compatibility with existing basic profiles
- **Enhanced Profiles**: MaterialProfile, AMSConfiguration, temperature validation
- **Material Compatibility Matrix**: Material type support validation
- **Printer Model Normalization**: Consistent model naming (spaces→hyphens, lowercase)

### 4. Color-to-Spool Assignment Optimization

- **Greedy Algorithm**: Fast assignment with color distance optimization
- **Optimal Algorithm**: Exhaustive search for best overall assignment (small palettes)
- **Constraint Validation**: AMS slot limits, material compatibility, color tolerance
- **Assignment Metrics**: Success rate, average ΔE, utilization statistics

### Key Classes

- **SpoolAssignmentOptimizer**: Core assignment engine
- **AssignmentResult**: Comprehensive assignment outcome with metrics
- **ColorAssignment**: Individual color→spool mapping with ΔE distance

### Color Matching Algorithm

1. **Input**: RGB color palette from texture quantization
2. **Conversion**: RGB → LAB for perceptual accuracy  
3. **Filtering**: Printer-compatible spools only
4. **Distance Calculation**: Delta E 2000 for each color→spool pair
5. **Assignment**: Greedy or optimal algorithm within tolerance threshold
6. **Validation**: AMS slot constraints and material compatibility

### Printer Compatibility System

- **Model Normalization**: "Bambu P1S" → "bambu-p1s"
- **Legacy Support**: Profiles without material restrictions accept all materials
- **Enhanced Validation**: Material type checking for enhanced profiles
- **Multi-Vendor**: Bambu Lab, Prusa Research support patterns
