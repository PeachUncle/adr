# ADR-008: Interactive Drill-Down Modals

## Status
Proposed

## Context
Engineering managers need the ability to investigate organizational metrics in detail without losing context of their starting point. Currently, the dashboard provides high-level overview metrics, but lacks seamless drill-down capabilities to explore underlying data, team compositions, and individual profiles.

### User Experience Challenges
- **Context switching**: Navigation away from dashboard loses original context
- **Cognitive load**: Multiple tabs/windows create mental overhead
- **Investigation friction**: Difficulty exploring "why" behind metrics
- **Mobile limitations**: Limited screen space for detailed exploration
- **Data relationships**: Hard to see connections between overview and details

### Management Use Cases
- **Investigating anomalies**: "Why does this team have low skill coverage?"
- **Resource planning**: "Who are the senior engineers available for new projects?"
- **Succession analysis**: "What's the experience distribution in the Phoenix Squad?"
- **Risk assessment**: "Which individuals are single points of failure?"
- **Performance correlation**: "How do team metrics relate to individual contributions?"

### Technical Requirements
- **Progressive disclosure**: Show appropriate level of detail for each drill-down
- **Context preservation**: Maintain navigation breadcrumbs and return paths
- **Performance optimization**: Lazy load detailed data only when requested
- **Access control**: Respect role-based permissions for detailed information
- **Mobile responsiveness**: Work effectively on all screen sizes

## Decision
We will implement an **Interactive Drill-Down Modal System** that provides seamless exploration from dashboard overview metrics to detailed views through layered modals with progressive disclosure.

### Core Principles

#### 1. Progressive Disclosure
Information revealed in layers based on user interest and authorization:
- **Level 1**: Summary metrics and basic context
- **Level 2**: Team/group composition and trends
- **Level 3**: Individual profiles and detailed analysis
- **Level 4**: Historical data and predictive insights

#### 2. Context Preservation
Users always know where they are and how they got there:
- **Breadcrumb navigation**: Clear path from overview to current detail
- **Modal layering**: Previous context visible behind current modal
- **Return navigation**: Easy path back to any previous level
- **State persistence**: Maintain filters and selections across drill-downs

#### 3. Performance-First Architecture
Fast, responsive interaction patterns:
- **Lazy loading**: Fetch detailed data only when modal opens
- **Intelligent caching**: Cache frequently accessed detail views
- **Optimistic UI**: Show loading states with skeleton content
- **Incremental loading**: Load additional details on demand

#### 4. Role-Based Detail Access
Appropriate information disclosure based on management level:
- **Team members**: Basic team information, no individual details
- **Engineering Managers**: Full team details, limited cross-team visibility
- **Directors**: Multi-team analysis, aggregated individual insights
- **VPs/CTOs**: Organization-wide detailed analysis

## Frontend Implementation

### JavaScript Modal Controller
```javascript
class DrillDownController {
  constructor() {
    this.modalStack = [];
    this.currentLevel = -1;
  }
  
  pushLevel(type, context = {}) {
    this.currentLevel++;
    
    const modal = {
      type: type,
      context: context,
      element: this.createModalElement(),
      data: null
    };
    
    this.modalStack.push(modal);
    this.loadModalData(modal).then(() => {
      this.renderModal(modal);
      this.showModal(modal);
    });
  }
  
  popLevel() {
    if (this.currentLevel >= 0) {
      const modal = this.modalStack.pop();
      this.hideModal(modal);
      this.currentLevel--;
    }
  }
  
  popToLevel(targetLevel) {
    while (this.currentLevel > targetLevel) {
      this.popLevel();
    }
  }
  
  async loadModalData(modal) {
    const response = await fetch('/dashboard/drill_down', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'X-CSRF-Token': document.querySelector('[name="csrf-token"]').content
      },
      body: JSON.stringify({
        type: modal.type,
        context: modal.context
      })
    });
    
    modal.data = await response.json();
  }
  
  renderModal(modal) {
    // Render modal content based on type and data
    modal.element.innerHTML = this.getTemplate(modal.type, modal.data);
  }
  
  showModal(modal) {
    document.body.appendChild(modal.element);
    modal.element.classList.add('modal-visible');
  }
  
  hideModal(modal) {
    modal.element.classList.remove('modal-visible');
    setTimeout(() => {
      if (modal.element.parentNode) {
        document.body.removeChild(modal.element);
      }
    }, 300); // Animation duration
  }
}

// Global instance
window.DrillDown = new DrillDownController();
```

## Data Loading & Caching Strategy

### Rails Controller Extension
```ruby
class DashboardController < ApplicationController
  def drill_down
    drill_down_type = params[:type]
    context = params[:context]
    
    # Authorize access based on context and user role
    authorize_drill_down_access!(drill_down_type, context)
    
    # Load appropriate data based on type
    data = DrillDownDataService.load_for_level(
      drill_down_type.to_sym, 
      context.symbolize_keys, 
      current_user
    )
    
    render json: {
      type: drill_down_type,
      context: context,
      data: data,
      template: render_to_string(
        partial: "drill_down/#{drill_down_type}",
        locals: { data: data },
        layout: false
      )
    }
  end
  
  private
  
  def authorize_drill_down_access!(type, context)
    case type
    when 'team_detail', 'team_composition'
      team = Organization::Team.find(context['team_id'])
      authorize team, :show?
    when 'individual_profile'
      user = User.find(context['user_id'])
      authorize user, :show_detailed_profile?
    end
  end
end
```

### Caching Strategy
```ruby
class DrillDownDataService
  CACHE_DURATION = 5.minutes
  
  def self.load_for_level(level, context, current_user)
    cache_key = build_cache_key(level, context, current_user)
    
    Rails.cache.fetch(cache_key, expires_in: CACHE_DURATION) do
      case level
      when :team_summary
        load_team_summary_data(context[:team_id], current_user)
      when :team_composition
        load_team_composition_data(context[:team_id], current_user)
      when :individual_profile
        load_individual_profile_data(context[:user_id], current_user)
      end
    end
  end
  
  private
  
  def self.build_cache_key(level, context, current_user)
    context_hash = Digest::SHA1.hexdigest(context.to_json)
    "drill_down:#{level}:#{context_hash}:#{current_user.id}:#{current_user.current_role&.code}"
  end
end
```

## Risk Mitigation

### Performance Risks
- **Modal memory leaks**: Proper cleanup of modal DOM elements
- **Cache invalidation**: Stale data in drill-down views
- **Mobile performance**: Large modals on small screens

**Mitigations:**
- Implement proper modal lifecycle management
- Smart cache invalidation based on data changes
- Adaptive content loading for mobile devices

### Privacy & Security Risks
- **Unauthorized data access**: Drill-down bypassing access controls
- **Data exposure**: Too much detail visible to wrong roles
- **Audit trail gaps**: Missing logs for detailed data access

**Mitigations:**
- Comprehensive authorization checks at every level
- Role-based content filtering
- Detailed audit logging for all drill-down access

### User Experience Risks
- **Navigation confusion**: Users lost in modal stack
- **Context loss**: Forgetting original investigation purpose
- **Mobile usability**: Poor experience on touch devices

**Mitigations:**
- Clear breadcrumb navigation at all levels
- Context preservation in modal headers
- Touch-optimized mobile interface design

## Decision Outcome
Implement an Interactive Drill-Down Modal System that enables seamless exploration from dashboard overview metrics to detailed team and individual profiles. The system will provide progressive disclosure with proper context preservation, role-based access controls, and optimized performance for both desktop and mobile experiences.

The implementation prioritizes user workflow efficiency and data exploration over comprehensive data display, ensuring managers can quickly investigate organizational metrics while maintaining appropriate privacy and security boundaries.
