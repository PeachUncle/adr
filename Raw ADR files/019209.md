# ADR-012: Hetzner VPS Deployment

## Status

Accepted (January 2026)

## Context

Need to deploy Trama as a showcase/portfolio project with:
- **Budget**: $10-20/month maximum
- **Goal**: Demonstrate complete architecture with full observability
- **Audience**: Portfolio visitors, not production users
- **Requirements**: Zero vendor lock-in, same stack as local development

## Decision

Deploy on **Hetzner Cloud CX33 VPS** (4 vCPU, 8GB RAM) for €6.46/month (~$7/month) using Docker Compose.

**Architecture:**
- Single VPS running all services via docker-compose.yml
- Memory-optimized configurations for comfortable operation
- Same stack as local development (PostgreSQL, Redis, Elasticsearch, full observability)
- Traefik edge proxy with automatic Let's Encrypt SSL

**Why Hetzner:**
- Best price/performance ($7/month vs $70-113/month on Azure/AWS)
- Zero vendor lock-in (can move to any VPS provider in 30 minutes)
- 100% portable (same docker-compose.yml everywhere)
- 8GB RAM provides comfortable headroom for all services

## Consequences

### Positive
- Extremely cheap: $7/month (94% cheaper than cloud alternatives)
- Zero vendor lock-in: Standard VPS, can move anywhere
- Complete observability: Full stack deployed for showcase
- Simple deployment: `docker compose --profile production up -d`
- Comfortable resources: 8GB RAM handles all services without pressure
- Learning opportunity: Demonstrates DevOps skills
- Automated CI/CD: GitHub Actions handles everything

### Negative
- Single point of failure (acceptable for showcase)
- Manual OS operations (updates, backups)
- No auto-scaling (fixed capacity)
- Not production-ready for high traffic

## Alternatives Considered

- **Azure Container Apps**: $113/month (16x more expensive)
- **Azure VM**: $70/month (10x more expensive)  
- **DigitalOcean**: $24/month (3.5x more expensive)
- **AWS Lightsail**: $20/month (3x more expensive)
- **Hetzner CX23 (4GB)**: €4.10/month - Too tight for full observability stack

All rejected due to cost or insufficient resources. Hetzner CX33 provides best balance of cost and capability.
