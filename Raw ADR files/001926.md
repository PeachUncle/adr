# Creation of a manuals directory

* Status: Accepted
* Deciders: Oihana Elizagoyen, Xabier Mikel Gutierrez, Aimar Uriarte
* Date: 2025/05/03

## Context and Problem Statement

The project has been growing and evolving, and it is important to have a well-organized structure for documentation. The creation of a dedicated directory for manuals will help in maintaining and developing the documentation in a more efficient way. This directory will serve as a central location for all manuals related to the project, making it easier for team members to find and access the information they need, such as deployment instructions.

## Decision Drivers

- **Organization**: A dedicated directory for manuals will help in keeping the documentation organized and easily accessible.
- **Ease of access**: Team members should be able to quickly find the information they need without having to search through multiple directories or files.
- **Scalability**: As the project grows, having a dedicated directory for manuals will make it easier to add new documentation without cluttering the existing structure.
- **Facilitation of external review**: Clear and centralized documentation ensures that external reviewers can easily understand and evaluate the project without unnecessary confusion or delays.
- **Facilitation of onboarding**: New team members can quickly get up to speed with the project by accessing the manuals in a dedicated directory, reducing the learning curve and improving productivity.

## Positive Consequences

- **Improved organization**: The creation of a dedicated directory for manuals will lead to better organization of documentation, making it easier to find and access information.
- **Easier onboarding**: New team members will have a centralized location to access manuals, reducing the time it takes for them to get up to speed with the project.
- **Facilitated external review**: Clear and centralized documentation will make it easier for external reviewers to understand the project, leading to more efficient evaluations.
- **Scalability**: The dedicated directory will allow for easy addition of new manuals as the project grows, without cluttering the existing structure.
  
## Negative Consequences

- **Initial effort**: There will be an initial effort required to create the directory and move existing manuals into it.
- **Maintenance**: The new directory will require ongoing maintenance to ensure that the manuals are kept up to date and organized.
