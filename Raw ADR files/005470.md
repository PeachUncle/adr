## Context

Agents in the multi-agent trading system require standardized access to:
- Interactive Brokers market data and order execution
- Greeks calculation services (Black-Scholes, numerical methods)
- Risk validation services (position limits, correlation checks)
- Market analysis services (VIX data, volatility surfaces)
- Database queries (historical trades, performance metrics)

Current challenges:
- No standardized tool invocation protocol across agents
- Direct API coupling creates brittle dependencies
- Difficult to mock/test agent behavior with external services
- No centralized authentication/authorization for tool access
- Agent code tightly coupled to service implementations

Model Context Protocol (MCP) provides:
- Standardized tool schema definitions
- Server-based tool implementations (decoupled from agents)
- Built-in authentication and session management
- Transport-agnostic communication (HTTP, stdio, WebSocket)
- Tool discovery and capability negotiation

## Decision

Adopt Model Context Protocol (MCP) as the standardized interface for all agent tools with dedicated MCP servers for each service domain.

### MCP Architecture

**MCP Server Types**:
1. **IB Gateway MCP Server**: Market data, order execution, account info
2. **Greeks MCP Server**: Options pricing, Greeks calculations
3. **Risk Management MCP Server**: Position validation, limit checks
4. **Market Analysis MCP Server**: VIX data, volatility surfaces, correlations
5. **Database MCP Server**: Historical queries, performance analytics

**Communication Pattern**:
```
Agent (MCP Client) → MCP Server → Backend Service
                   ←            ←
```

**Transport**: HTTP/2 over internal VPC network (Cloud Run to Cloud Run)

## Architecture

### MCP Server Structure

**Base MCP Server** (shared foundation):

```python
from mcp import MCPServer, Tool, ToolParameter, ToolResult
from typing import List, Dict, Any
import asyncio

class BaseMCPServer(MCPServer):
    """Base class for all MCP servers"""

    def __init__(self, name: str, version: str):
        super().__init__(name=name, version=version)
        self.auth_enabled = True
        self.rate_limiter = RateLimiter()

    async def authenticate(self, token: str) -> bool:
        """Verify agent service account token"""
        # Validate Google Cloud IAM token
        credentials = await verify_iam_token(token)
        return credentials.service_account in self.allowed_service_accounts

    async def handle_request(self, request: MCPRequest) -> MCPResponse:
        """Request handler with auth and rate limiting"""
        if self.auth_enabled:
            if not await self.authenticate(request.auth_token):
                return MCPResponse(error="Authentication failed")

        if not await self.rate_limiter.allow(request.client_id):
            return MCPResponse(error="Rate limit exceeded")

        return await super().handle_request(request)

    def register_tools(self):
        """Override in subclasses to register domain-specific tools"""
        raise NotImplementedError
```

```python
from mcp import Tool, ToolParameter
from ib_insync import IB, Stock, Option, Contract
import asyncio

class IBGatewayMCPServer(BaseMCPServer):
    def __init__(self):
        super().__init__(name="ib_gateway", version="1.0.0")
        self.ib = IB()
        self.connected = False
        self.register_tools()

    async def connect_ib(self):
        """Establish connection to IB Gateway"""
        if not self.connected:
            await self.ib.connectAsync(
                host=os.getenv("IB_HOST", "localhost"),
                port=int(os.getenv("IB_PORT", 4002)),
                clientId=1
            )
            self.connected = True

    def register_tools(self):
        """Register IB-specific tools"""

        @self.tool(
            name="get_options_chain",
            description="Fetch options chain for a given underlying symbol",
            parameters=[
                ToolParameter(name="symbol", type="string", required=True,
                            description="Underlying stock symbol (e.g., 'AAPL')"),
                ToolParameter(name="expiration", type="string", required=True,
                            description="Expiration date in YYYYMMDD format"),
                ToolParameter(name="strike_range", type="number", required=False,
                            description="Strike range percentage (default: 0.10)")
            ]
        )
        async def get_options_chain(symbol: str, expiration: str,
                                   strike_range: float = 0.10) -> ToolResult:
            """Fetch options chain from IB"""
            await self.connect_ib()

            # Get underlying price
            stock = Stock(symbol, 'SMART', 'USD')
            await self.ib.qualifyContractsAsync(stock)
            ticker = self.ib.reqMktData(stock)
            await asyncio.sleep(1)
            underlying_price = ticker.last

            # Calculate strike range
            min_strike = underlying_price * (1 - strike_range)
            max_strike = underlying_price * (1 + strike_range)

            # Fetch options chain
            chains = await self.ib.reqSecDefOptParamsAsync(
                underlyingSymbol=symbol,
                futFopExchange='',
                underlyingSecType='STK',
                underlyingConId=stock.conId
            )

            # Filter by expiration and strike range
            options = []
            for chain in chains:
                if expiration in chain.expirations:
                    for strike in chain.strikes:
                        if min_strike <= strike <= max_strike:
                            # Request both call and put
                            call = Option(symbol, expiration, strike, 'C', 'SMART')
                            put = Option(symbol, expiration, strike, 'P', 'SMART')

                            contracts = await self.ib.qualifyContractsAsync(call, put)
                            tickers = self.ib.reqMktData(contracts[0]), \
                                     self.ib.reqMktData(contracts[1])
                            await asyncio.sleep(0.5)

                            options.append({
                                "strike": strike,
                                "call": {
                                    "bid": tickers[0].bid,
                                    "ask": tickers[0].ask,
                                    "last": tickers[0].last,
                                    "volume": tickers[0].volume,
                                    "open_interest": tickers[0].openInterest,
                                    "iv": tickers[0].impliedVolatility
                                },
                                "put": {
                                    "bid": tickers[1].bid,
                                    "ask": tickers[1].ask,
                                    "last": tickers[1].last,
                                    "volume": tickers[1].volume,
                                    "open_interest": tickers[1].openInterest,
                                    "iv": tickers[1].impliedVolatility
                                }
                            })

            return ToolResult(
                success=True,
                data={
                    "symbol": symbol,
                    "underlying_price": underlying_price,
                    "expiration": expiration,
                    "options": options
                }
            )

        @self.tool(
            name="execute_order",
            description="Execute an options order through IB Gateway",
            parameters=[
                ToolParameter(name="symbol", type="string", required=True),
                ToolParameter(name="strike", type="number", required=True),
                ToolParameter(name="expiration", type="string", required=True),
                ToolParameter(name="right", type="string", required=True,
                            description="'C' for Call, 'P' for Put"),
                ToolParameter(name="action", type="string", required=True,
                            description="'BUY' or 'SELL'"),
                ToolParameter(name="quantity", type="integer", required=True),
                ToolParameter(name="order_type", type="string", required=True,
                            description="'LMT', 'MKT', or 'MID'"),
                ToolParameter(name="limit_price", type="number", required=False)
            ]
        )
        async def execute_order(symbol: str, strike: float, expiration: str,
                              right: str, action: str, quantity: int,
                              order_type: str, limit_price: float = None) -> ToolResult:
            """Execute order with IB Gateway"""
            await self.connect_ib()

            # Create contract
            contract = Option(symbol, expiration, strike, right, 'SMART')
            await self.ib.qualifyContractsAsync(contract)

            # Create order
            if order_type == 'LMT':
                order = LimitOrder(action, quantity, limit_price)
            elif order_type == 'MKT':
                order = MarketOrder(action, quantity)
            elif order_type == 'MID':
                # Calculate mid price
                ticker = self.ib.reqMktData(contract)
                await asyncio.sleep(1)
                mid_price = (ticker.bid + ticker.ask) / 2
                order = LimitOrder(action, quantity, mid_price)

            # Place order
            trade = self.ib.placeOrder(contract, order)
            await asyncio.sleep(2)  # Wait for fill

            return ToolResult(
                success=trade.isDone(),
                data={
                    "order_id": trade.order.orderId,
                    "status": trade.orderStatus.status,
                    "filled": trade.orderStatus.filled,
                    "remaining": trade.orderStatus.remaining,
                    "avg_fill_price": trade.orderStatus.avgFillPrice
                }
            )

        @self.tool(
            name="get_account_summary",
            description="Get account balance and position summary",
            parameters=[]
        )
        async def get_account_summary() -> ToolResult:
            """Fetch account summary from IB"""
            await self.connect_ib()

            account_values = self.ib.accountValues()
            positions = self.ib.positions()

            summary = {
                "net_liquidation": next(
                    (v.value for v in account_values
                     if v.tag == 'NetLiquidation'), 0
                ),
                "available_funds": next(
                    (v.value for v in account_values
                     if v.tag == 'AvailableFunds'), 0
                ),
                "buying_power": next(
                    (v.value for v in account_values
                     if v.tag == 'BuyingPower'), 0
                ),
                "positions": [
                    {
                        "symbol": p.contract.symbol,
                        "position": p.position,
                        "avg_cost": p.avgCost,
                        "market_value": p.marketValue
                    }
                    for p in positions
                ]
            }

            return ToolResult(success=True, data=summary)

        @self.tool(
            name="get_market_data",
            description="Get real-time market data for a symbol",
            parameters=[
                ToolParameter(name="symbol", type="string", required=True),
                ToolParameter(name="sec_type", type="string", required=True,
                            description="'STK' or 'OPT'"),
                ToolParameter(name="strike", type="number", required=False),
                ToolParameter(name="expiration", type="string", required=False),
                ToolParameter(name="right", type="string", required=False)
            ]
        )
        async def get_market_data(symbol: str, sec_type: str,
                                 strike: float = None, expiration: str = None,
                                 right: str = None) -> ToolResult:
            """Fetch real-time market data"""
            await self.connect_ib()

            if sec_type == 'STK':
                contract = Stock(symbol, 'SMART', 'USD')
            else:
                contract = Option(symbol, expiration, strike, right, 'SMART')

            await self.ib.qualifyContractsAsync(contract)
            ticker = self.ib.reqMktData(contract)
            await asyncio.sleep(1)

            return ToolResult(
                success=True,
                data={
                    "symbol": symbol,
                    "last": ticker.last,
                    "bid": ticker.bid,
                    "ask": ticker.ask,
                    "volume": ticker.volume,
                    "open": ticker.open,
                    "high": ticker.high,
                    "low": ticker.low,
                    "close": ticker.close
                }
            )
```

### 2. Greeks Calculation MCP Server

**Purpose**: Options pricing and Greeks calculations

**Tool Definitions**:

```python
from mcp import Tool, ToolParameter
from scipy.stats import norm
import numpy as np

class GreeksMCPServer(BaseMCPServer):
    def __init__(self):
        super().__init__(name="greeks_calculator", version="1.0.0")
        self.register_tools()

    def register_tools(self):
        """Register Greeks calculation tools"""

        @self.tool(
            name="calculate_greeks",
            description="Calculate option Greeks using Black-Scholes model",
            parameters=[
                ToolParameter(name="underlying_price", type="number", required=True),
                ToolParameter(name="strike_price", type="number", required=True),
                ToolParameter(name="time_to_expiry", type="number", required=True,
                            description="Time to expiration in years"),
                ToolParameter(name="volatility", type="number", required=True,
                            description="Implied volatility (e.g., 0.25 for 25%)"),
                ToolParameter(name="risk_free_rate", type="number", required=True,
                            description="Risk-free rate (e.g., 0.05 for 5%)"),
                ToolParameter(name="option_type", type="string", required=True,
                            description="'call' or 'put'"),
                ToolParameter(name="dividend_yield", type="number", required=False,
                            description="Annual dividend yield (default: 0)")
            ]
        )
        async def calculate_greeks(
            underlying_price: float,
            strike_price: float,
            time_to_expiry: float,
            volatility: float,
            risk_free_rate: float,
            option_type: str,
            dividend_yield: float = 0.0
        ) -> ToolResult:
            """Black-Scholes Greeks calculation"""

            S = underlying_price
            K = strike_price
            T = time_to_expiry
            sigma = volatility
            r = risk_free_rate
            q = dividend_yield

            # Calculate d1 and d2
            d1 = (np.log(S / K) + (r - q + 0.5 * sigma**2) * T) / \
                 (sigma * np.sqrt(T))
            d2 = d1 - sigma * np.sqrt(T)

            # Calculate Greeks
            if option_type.lower() == 'call':
                delta = np.exp(-q * T) * norm.cdf(d1)
                theta = (
                    -S * norm.pdf(d1) * sigma * np.exp(-q * T) / (2 * np.sqrt(T))
                    - r * K * np.exp(-r * T) * norm.cdf(d2)
                    + q * S * np.exp(-q * T) * norm.cdf(d1)
                ) / 365  # Daily theta
            else:  # put
                delta = np.exp(-q * T) * (norm.cdf(d1) - 1)
                theta = (
                    -S * norm.pdf(d1) * sigma * np.exp(-q * T) / (2 * np.sqrt(T))
                    + r * K * np.exp(-r * T) * norm.cdf(-d2)
                    - q * S * np.exp(-q * T) * norm.cdf(-d1)
                ) / 365  # Daily theta

            gamma = norm.pdf(d1) * np.exp(-q * T) / (S * sigma * np.sqrt(T))
            vega = S * norm.pdf(d1) * np.sqrt(T) * np.exp(-q * T) / 100  # Per 1% IV change
            rho = (
                K * T * np.exp(-r * T) * norm.cdf(d2)
                if option_type.lower() == 'call'
                else -K * T * np.exp(-r * T) * norm.cdf(-d2)
            ) / 100  # Per 1% rate change

            return ToolResult(
                success=True,
                data={
                    "delta": round(delta, 4),
                    "gamma": round(gamma, 4),
                    "theta": round(theta, 4),
                    "vega": round(vega, 4),
                    "rho": round(rho, 4),
                    "calculation_method": "Black-Scholes"
                }
            )

        @self.tool(
            name="calculate_portfolio_greeks",
            description="Calculate aggregate Greeks for a portfolio of positions",
            parameters=[
                ToolParameter(name="positions", type="array", required=True,
                            description="Array of position objects with greeks and quantity")
            ]
        )
        async def calculate_portfolio_greeks(positions: List[Dict]) -> ToolResult:
            """Aggregate portfolio Greeks"""

            portfolio_delta = sum(p['delta'] * p['quantity'] for p in positions)
            portfolio_gamma = sum(p['gamma'] * p['quantity'] for p in positions)
            portfolio_theta = sum(p['theta'] * p['quantity'] for p in positions)
            portfolio_vega = sum(p['vega'] * p['quantity'] for p in positions)

            return ToolResult(
                success=True,
                data={
                    "portfolio_delta": round(portfolio_delta, 2),
                    "portfolio_gamma": round(portfolio_gamma, 4),
                    "portfolio_theta": round(portfolio_theta, 2),
                    "portfolio_vega": round(portfolio_vega, 2),
                    "position_count": len(positions)
                }
            )

        @self.tool(
            name="calculate_implied_volatility",
            description="Calculate implied volatility from option price",
            parameters=[
                ToolParameter(name="option_price", type="number", required=True),
                ToolParameter(name="underlying_price", type="number", required=True),
                ToolParameter(name="strike_price", type="number", required=True),
                ToolParameter(name="time_to_expiry", type="number", required=True),
                ToolParameter(name="risk_free_rate", type="number", required=True),
                ToolParameter(name="option_type", type="string", required=True)
            ]
        )
        async def calculate_implied_volatility(
            option_price: float,
            underlying_price: float,
            strike_price: float,
            time_to_expiry: float,
            risk_free_rate: float,
            option_type: str
        ) -> ToolResult:
            """Newton-Raphson IV calculation"""

            # Implementation of Newton-Raphson method for IV
            iv = 0.25  # Initial guess
            max_iterations = 100
            tolerance = 1e-5

            for i in range(max_iterations):
                # Calculate option price with current IV
                d1 = (np.log(underlying_price / strike_price) +
                     (risk_free_rate + 0.5 * iv**2) * time_to_expiry) / \
                     (iv * np.sqrt(time_to_expiry))
                d2 = d1 - iv * np.sqrt(time_to_expiry)

                if option_type.lower() == 'call':
                    calc_price = (underlying_price * norm.cdf(d1) -
                                strike_price * np.exp(-risk_free_rate * time_to_expiry) *
                                norm.cdf(d2))
                else:
                    calc_price = (strike_price * np.exp(-risk_free_rate * time_to_expiry) *
                                norm.cdf(-d2) - underlying_price * norm.cdf(-d1))

                # Calculate vega for iteration
                vega = underlying_price * norm.pdf(d1) * np.sqrt(time_to_expiry)

                # Newton-Raphson update
                price_diff = calc_price - option_price
                if abs(price_diff) < tolerance:
                    return ToolResult(
                        success=True,
                        data={
                            "implied_volatility": round(iv, 4),
                            "iterations": i + 1
                        }
                    )

                iv = iv - price_diff / vega

            return ToolResult(
                success=False,
                error="IV calculation did not converge"
            )
```

### 3. Risk Management MCP Server

**Purpose**: Position validation and risk limit checks

**Tool Definitions**:

```python
class RiskManagementMCPServer(BaseMCPServer):
    def __init__(self):
        super().__init__(name="risk_management", version="1.0.0")
        self.risk_config = self.load_risk_config()
        self.register_tools()

    def load_risk_config(self) -> Dict:
        """Load risk parameters from ADR-008 config"""
        import yaml
        with open('/app/config/risk.yaml', 'r') as f:
            return yaml.safe_load(f)

    def register_tools(self):
        """Register risk validation tools"""

        @self.tool(
            name="validate_new_position",
            description="Validate if a new position meets risk requirements",
            parameters=[
                ToolParameter(name="symbol", type="string", required=True),
                ToolParameter(name="strategy_type", type="string", required=True),
                ToolParameter(name="position_size", type="number", required=True),
                ToolParameter(name="max_loss", type="number", required=True),
                ToolParameter(name="portfolio_greeks", type="object", required=True),
                ToolParameter(name="current_positions", type="array", required=True)
            ]
        )
        async def validate_new_position(
            symbol: str,
            strategy_type: str,
            position_size: float,
            max_loss: float,
            portfolio_greeks: Dict,
            current_positions: List[Dict]
        ) -> ToolResult:
            """Comprehensive position validation"""

            violations = []

            # Check max open positions
            if len(current_positions) >= self.risk_config['max_open_positions']:
                violations.append({
                    "rule": "MAX_OPEN_POSITIONS",
                    "limit": self.risk_config['max_open_positions'],
                    "current": len(current_positions)
                })

            # Check portfolio heat
            account_value = await self.get_account_value()
            total_risk = sum(p.get('max_loss', 0) for p in current_positions) + max_loss
            portfolio_heat = total_risk / account_value

            if portfolio_heat > self.risk_config['max_portfolio_heat']:
                violations.append({
                    "rule": "MAX_PORTFOLIO_HEAT",
                    "limit": self.risk_config['max_portfolio_heat'],
                    "current": portfolio_heat
                })

            # Check portfolio delta (ADR-008)
            new_delta = portfolio_greeks.get('delta', 0)
            delta_limit = self.risk_config.get('max_portfolio_delta', 200)

            if abs(new_delta) > delta_limit:
                violations.append({
                    "rule": "MAX_PORTFOLIO_DELTA",
                    "limit": delta_limit,
                    "current": abs(new_delta)
                })

            # Check correlation (call correlation service)
            correlation_check = await self.check_correlation(symbol, current_positions)
            if correlation_check['max_correlation'] > 0.8:
                violations.append({
                    "rule": "MAX_CORRELATION",
                    "limit": 0.8,
                    "current": correlation_check['max_correlation'],
                    "correlated_with": correlation_check['symbol']
                })

            # Check VIX threshold
            vix = await self.get_current_vix()
            if vix > self.risk_config['max_vix_for_new_trades']:
                violations.append({
                    "rule": "MAX_VIX_FOR_NEW_TRADES",
                    "limit": self.risk_config['max_vix_for_new_trades'],
                    "current": vix
                })

            # Circuit breaker checks
            if vix > self.risk_config['circuit_breaker_vix']:
                violations.append({
                    "rule": "CIRCUIT_BREAKER_VIX",
                    "limit": self.risk_config['circuit_breaker_vix'],
                    "current": vix,
                    "severity": "CRITICAL"
                })

            approved = len(violations) == 0

            return ToolResult(
                success=True,
                data={
                    "approved": approved,
                    "violations": violations,
                    "risk_metrics": {
                        "portfolio_heat": portfolio_heat,
                        "portfolio_delta": new_delta,
                        "vix": vix,
                        "position_count": len(current_positions) + 1
                    }
                }
            )

        @self.tool(
            name="check_circuit_breakers",
            description="Check if any circuit breakers are triggered",
            parameters=[]
        )
        async def check_circuit_breakers() -> ToolResult:
            """Check all circuit breaker conditions"""

            breakers_triggered = []

            # VIX circuit breaker
            vix = await self.get_current_vix()
            if vix > self.risk_config['circuit_breaker_vix']:
                breakers_triggered.append({
                    "type": "VIX_SPIKE",
                    "threshold": self.risk_config['circuit_breaker_vix'],
                    "current": vix,
                    "action": "HALT_ALL_NEW_TRADES"
                })

            # Daily loss circuit breaker
            daily_pnl = await self.get_daily_pnl()
            account_value = await self.get_account_value()
            daily_loss_pct = abs(daily_pnl) / account_value

            if daily_pnl < 0 and daily_loss_pct > self.risk_config['circuit_breaker_daily_loss']:
                breakers_triggered.append({
                    "type": "DAILY_LOSS",
                    "threshold": self.risk_config['circuit_breaker_daily_loss'],
                    "current": daily_loss_pct,
                    "action": "CLOSE_ALL_POSITIONS"
                })

            # Correlation circuit breaker
            correlation_matrix = await self.get_correlation_matrix()
            max_corr = np.max(np.abs(correlation_matrix - np.eye(len(correlation_matrix))))

            if max_corr > self.risk_config['circuit_breaker_correlation']:
                breakers_triggered.append({
                    "type": "HIGH_CORRELATION",
                    "threshold": self.risk_config['circuit_breaker_correlation'],
                    "current": max_corr,
                    "action": "HALT_NEW_CORRELATED_TRADES"
                })

            return ToolResult(
                success=True,
                data={
                    "breakers_active": len(breakers_triggered) > 0,
                    "breakers": breakers_triggered
                }
            )

        @self.tool(
            name="calculate_position_sizing",
            description="Calculate appropriate position size based on risk parameters",
            parameters=[
                ToolParameter(name="strategy_type", type="string", required=True),
                ToolParameter(name="premium_received", type="number", required=True),
                ToolParameter(name="max_loss_per_contract", type="number", required=True),
                ToolParameter(name="current_portfolio_heat", type="number", required=True)
            ]
        )
        async def calculate_position_sizing(
            strategy_type: str,
            premium_received: float,
            max_loss_per_contract: float,
            current_portfolio_heat: float
        ) -> ToolResult:
            """Calculate max contracts based on risk budget"""

            account_value = await self.get_account_value()
            max_heat = self.risk_config['max_portfolio_heat']
            available_heat = max_heat - current_portfolio_heat

            # Maximum dollar risk available
            max_dollar_risk = account_value * available_heat

            # Calculate max contracts
            max_contracts = int(max_dollar_risk / max_loss_per_contract)

            # Apply strategy-specific limits
            strategy_limits = {
                'iron_condor': 5,
                'cash_secured_put': 5,
                'covered_call': 3,
                'bear_call_spread': 3
            }

            max_contracts = min(max_contracts, strategy_limits.get(strategy_type, 3))

            return ToolResult(
                success=True,
                data={
                    "max_contracts": max_contracts,
                    "max_dollar_risk": max_dollar_risk,
                    "available_heat": available_heat,
                    "strategy_limit": strategy_limits.get(strategy_type, 3)
                }
            )
```

from google.auth import default
from google.auth.transport.requests import Request

class MCPClient:
    def __init__(self, server_url: str):
        self.server_url = server_url
        self.credentials, _ = default()

    def get_auth_token(self) -> str:
        """Get IAM token for service account"""
        if not self.credentials.valid:
            self.credentials.refresh(Request())
        return self.credentials.token

    async def call_tool(self, tool_name: str, **kwargs):
        """Authenticated MCP tool call"""
        headers = {
            "Authorization": f"Bearer {self.get_auth_token()}",
            "Content-Type": "application/json"
        }

        response = await self.http_client.post(
            f"{self.server_url}/tools/{tool_name}",
            headers=headers,
            json=kwargs
        )

        return MCPResponse.from_json(response.json())

## Error Handling and Retries

**Retry Logic**:
```python
from tenacity import retry, stop_after_attempt, wait_exponential

class MCPClient:
    @retry(
        stop=stop_after_attempt(3),
        wait=wait_exponential(multiplier=1, min=1, max=10),
        reraise=True
    )
    async def call_tool(self, tool_name: str, **kwargs):
        """MCP tool call with automatic retries"""
        try:
            response = await self._make_request(tool_name, **kwargs)

            if response.status_code == 429:  # Rate limit
                raise RateLimitError("Rate limit exceeded")

            if response.status_code >= 500:  # Server error
                raise ServerError(f"Server error: {response.status_code}")

            return MCPResponse.from_json(response.json())

        except (TimeoutError, ConnectionError) as e:
            # Transient network errors - will retry
            raise
```

## Consequences

### Positive

1. **Decoupling**: Agents isolated from service implementations
2. **Testability**: Easy to mock MCP servers for agent testing
3. **Standardization**: Uniform tool interface across all agents
4. **Security**: Centralized authentication and rate limiting
5. **Observability**: Structured logging and metrics at tool level
6. **Scalability**: MCP servers scale independently from agents
7. **Versioning**: Tool schemas enable backward-compatible changes

### Negative

1. **Network Overhead**: MCP calls add latency vs direct function calls
2. **Complexity**: Additional layer between agents and services
3. **Dependency**: Agents depend on MCP server availability
4. **Debugging**: Distributed debugging across agent and MCP server

### Mitigation Strategies

**Latency**:
- HTTP/2 connection pooling
- Local caching for frequently-used data (VIX, account summary)
- Batch tool calls where possible

**Reliability**:
- Automatic retries with exponential backoff
- Circuit breakers to fail fast
- Health checks and automatic container restart

**Debugging**:
- Correlation IDs across agent → MCP → service
- Distributed tracing (Cloud Trace)
- Structured logging with request context
