# ADR-0001: Minimal SDXL Implementation with BDD Tests

## Status

In Progress 🚧 - 2025-01-11 (BDD test implementation in progress)

## Context

- Need to run SDXL efficiently on macOS
- Focus on core functionality in initial phase
- Need appropriate structure for future extensions
- Need testable design
- Adopt BDD approach for behavior-centric testing

## Decision

Starting with the following minimal configuration:

1. Code Structure

   ```
   sdxl_mac_diffusers_guide/
   ├── data/
   │   └── models/          # Model file location
   │       └── sdxl/
   ├── docs/
   │   └── adr/            # Architecture decision records
   ├── examples/           # Example scripts
   │   └── generate_images.py
   ├── src/
   │   └── sdxl_mac_diffusers_guide/
   │       └── core/
   │           ├── __init__.py
   │           └── pipeline.py      # Basic pipeline management
   └── tests/              # Test directory
       ├── features/       # BDD feature files
       │   ├── sdxl_pipeline.feature
       │   ├── device_management.feature
       │   └── data_type_management.feature
       ├── step_definitions/  # BDD test implementations
       │   ├── test_sdxl_pipeline.py
       │   ├── test_device_management.py
       │   └── test_data_type_management.py
       ├── conftest.py     # Common test fixtures
       └── README.md       # Test documentation
   ```

2. Initial Implementation Scope

   - Basic SDXL pipeline initialization and execution (✅ Complete)
