# ADR 001: Initial Project Setup

## Status

Accepted

## Context

We need to set up a new marketing insights application that allows users to upload marketing data files and analyze them using natural language queries. The application should be clean, minimalist, and easy to use.

## Decision

We've decided to create a full-stack application with the following architecture:

### Backend
- **Framework**: FastAPI (Python)
- **Database**: SQLite for development (can be replaced with PostgreSQL for production)
- **File Storage**: Local filesystem for development
- **Containerization**: Docker for development and production environments

### Frontend
- **Framework**: React with Vite
- **Language**: TypeScript
- **Styling**: Custom CSS (no framework) for a clean, minimalist design
- **Routing**: React Router for client-side routing
- **State Management**: React hooks for local state management

### Development Environment
- **Docker Compose** for local development
- Separate development and production Docker configurations
- Hot-reloading enabled for both frontend and backend

## Consequences

### Positive
- FastAPI provides a modern, high-performance API framework with automatic OpenAPI documentation
- React with Vite offers a fast development experience with hot module replacement
- TypeScript adds type safety to the frontend code
- Docker ensures consistent development and deployment environments
- Separate Docker configurations for development and production allow for optimized builds

### Negative
- Additional complexity of managing Docker containers
- Need to ensure proper communication between frontend and backend containers
- Custom CSS requires more manual styling work compared to using a CSS framework

### Neutral
- Using SQLite for development is simpler but will require configuration changes for production databases
- Local file storage is sufficient for development but will need to be replaced with a more robust solution for production

## Notes
- We chose not to use Tailwind CSS due to potential configuration issues and to maintain a simpler styling approach
- The application is structured to allow for easy extension with additional features in the future
