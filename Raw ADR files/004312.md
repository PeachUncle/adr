Summary
- Sprint-005 focuses on rounding out production readiness: stabilize workerized flows, harden offline/caching, finish translation QA, and ship lightweight visibility for metrics without collecting payloads.

Decision
- Schedule: proposed 2026-02-17 → 2026-02-28; two-week cadence; no net-new tools.
- Observability:
  - Keep `/api/tools/metrics` schema fixed; add server-side sampling enforcement and reject missing/invalid `sampleId`.
  - Add minimal admin-only metrics digest page (counts and error buckets only; no payloads); keep behind token.
  - Track budget breaches in dev console; add optional toast gated by env flag for debugging.
- Stability/workerization:
  - Finalize worker fallbacks for markdown-to-pdf and format-converter; add timeouts and user-facing recovery prompts.
  - Add smoke tests for worker and main-thread paths; block regressions that remove aria-live or 10MB cap.
- Offline & caching:
  - Ship safe asset/locale caching for offline-friendly usage; ensure failure paths degrade gracefully without `DATABASE_URL`.
  - Add size-aware progress + cancellation for >5MB reads across tools using shared UI patterns.
- i18n & content:
  - Run full translation QA; fill missing keys for metrics/offline UI; prevent hard-coded strings in tools touched.
- QA gates:
  - Require `npm run validate` and `npm run qa:translations` green; add focused Playwright smoke covering worker + offline cache behavior.

Rationale
- We need stability and visibility after introducing metrics/workerization, without expanding surface area or violating privacy/offline guarantees.

Out of scope
- New tools or payload-level analytics; raising the 10MB ceiling; non-admin dashboards.

Risks/Mitigations
- Worker regressions: keep main-thread fallback + timeouts + tests.
- Privacy drift: enforce schema + sampling server-side; no payloads; admin-only digest.
- Offline cache staleness: short TTLs and clear retry UX; avoid caching API writes.

Next steps
- Publish Sprint-005 checklist with owners and acceptance.
- Add admin metrics digest route and sampling guards.
- Ship offline/cache improvements and worker smoke tests; run validation + translation QA.
