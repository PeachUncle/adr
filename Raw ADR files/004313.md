Summary
- Two-week release-hardening sprint to graduate offline caching, lock in metrics/worker QA gates, and burn down performance/a11y debt before widening scope.

Decision
- Schedule: proposed 2026-03-03 → 2026-03-14; keep two-week cadence; no new tools.
- Offline & caching GA: ship safe asset/locale caching with cancel/progress UX; document 10MB cap/5MB progress; verify graceful degradation without `DATABASE_URL`.
- Metrics & budgets: refine admin metrics digest (error buckets + sampling info) and wire alerting thresholds (dev-only console/toast) for budget breaches; keep payload-free schema.
- Worker & performance hardening: finalize worker fallbacks/timeouts for markdown-to-pdf and format-converter; add bundle-size and render/action budget checks for top tools.
- QA gates: expand Playwright smokes for worker + offline + digest; keep `npm run validate` and `npm run qa:translations` blocking; add a11y sweep on impacted pages.
- i18n/content: backfill strings touched this sprint; eliminate new hard-coded copy; ensure digest/offline UX fully localized.

Rationale
- We need a stable offline/worker experience and lightweight observability before widening scope; release gates must prevent regressions on privacy, a11y, and performance.

Out of scope
- New tools or payload-level analytics; raising the 10MB ceiling; non-admin dashboards.

Risks/Mitigations
- Offline cache regressions: limit to safe assets/locales, add cancel/retry, keep short TTLs.
- Worker instability: retain main-thread fallback + 15s timeout + tests.
- Budget drift: enforce sampling and budget warnings; keep digest payload-free.

Next steps
- Publish sprint-006 checklist and owners.
- Land offline cache GA + progress/cancel components.
- Ship digest refinements, budgets, and Playwright/a11y coverage; run validation + translation QA.
