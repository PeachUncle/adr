# ADR-007: Testing Strategy for workflows4s + llm4s

**Status**: Proposed

## Question

What's the testing story for workflows4s + llm4s integration?

## Context

Testing LLM applications presents unique challenges:
- **Non-deterministic outputs**: LLMs produce varied responses
- **External dependencies**: API calls, MCP tools, network
- **Cost**: Testing against real LLM APIs is expensive
- **Workflow complexity**: Multi-step processes with state

We need a comprehensive testing strategy covering:
1. **Unit tests**: Pure domain logic
2. **Integration tests**: Workflow execution
3. **LLM mocking**: Testing without real API calls
4. **Contract tests**: Verifying LLM response schemas
5. **End-to-end tests**: Full workflow validation

Currently implemented:
- ✅ Domain model unit tests (5 tests passing)
- ❓ Workflow integration tests
- ❓ LLM interaction mocking
- ❓ Performance/load testing

## Decision

Adopt a **multi-layered testing strategy** that combines unit tests, workflow integration tests with mocked LLMs, and selective end-to-end tests.

### Testing Pyramid

```
        /\
       /E2E\        E2E (Real LLM, Expensive)
      /------\
     /Contract\     Contract (Response Schema)
    /----------\
   /Integration \   Integration (Mock LLM)
  /--------------\
 /   Unit Tests   \ Unit (Pure Logic)
/------------------\
```

### Layer 1: Unit Tests (Base)

**Purpose**: Test pure domain logic without workflows or LLMs.

**Tools**: ScalaTest, ScalaCheck (property-based)

**What to test**:
- Domain model validation
- Business logic
- Utilities and helpers
- Tool handlers (without LLM)
- Data transformations

**Example**:

```scala
package io.github.llm4s.tripper.domain

import org.scalatest.flatspec.AnyFlatSpec
import org.scalatest.matchers.should.Matchers

class TravelBriefSpec extends AnyFlatSpec with Matchers {
  
  "TravelBrief.toPromptContribution" should "format dates correctly" in {
    val brief: TravelBrief = TravelBrief(
      destination = "Paris",
      startDate = LocalDate.of(2024, 6, 1),
      endDate = LocalDate.of(2024, 6, 7),
      budget = Some(2000.0),
      preferences = List("museums", "cafes")
    )
    
    val contribution: String = brief.toPromptContribution
    
    assert(contribution.contains("Paris"))
    assert(contribution.contains("2024-06-01"))
    assert(contribution.contains("2024-06-07"))
    assert(contribution.contains("6 days"))
  }
  
  it should "handle missing budget" in {
    val brief: TravelBrief = TravelBrief(
      destination = "Tokyo",
      startDate = LocalDate.of(2024, 7, 1),
      endDate = LocalDate.of(2024, 7, 10),
      budget = None,
      preferences = List.empty
    )
    
    val contribution: String = brief.toPromptContribution
    
    assert(contribution.contains("Tokyo"))
    assert(!contribution.contains("budget"))
  }
}
```

### Layer 2: Workflow Integration Tests

**Purpose**: Test workflow execution with mocked LLMs.

**Tools**: workflows4s `InMemorySyncRuntime`, Mock LLMClient

**What to test**:
- Workflow state transitions
- Event sourcing (replay)
- Signal handling
- Error handling
- Timer/retry logic

#### Mock LLM Client

```scala
package io.github.llm4s.tripper.testing

import org.llm4s.llmconnect.LLMClient
import org.llm4s.llmconnect.model._
import org.llm4s.error.LLMError

/**
 * Mock LLM client for testing workflows.
 */
class MockLLMClient(responses: Map[String, String] = Map.empty) extends LLMClient {
  
  private var callCount: Int = 0
  private val defaultResponse: String = "Mock LLM response"
  
  override def complete(
    conversation: Conversation,
    options: CompletionOptions = CompletionOptions()
  ): Either[LLMError, Completion] = {
    callCount += 1
    
    // Extract user query from conversation
    val userQuery: String = conversation.messages
      .collect { case UserMessage(content) => content }
      .lastOption
      .getOrElse("")
    
    // Find matching response or use default
    val responseText: String = responses
      .find { case (pattern, _) => userQuery.contains(pattern) }
      .map(_._2)
      .getOrElse(defaultResponse)
    
    Right(Completion(
      id = s"test-completion-$callCount",
      created = System.currentTimeMillis() / 1000,
      model = "mock-model",
      message = AssistantMessage(responseText),
      usage = Some(TokenUsage(
        promptTokens = 10,
        completionTokens = 20,
        totalTokens = 30
      )),
      finishReason = Some("stop")
    ))
  }
  
  override def streamComplete(
    conversation: Conversation,
    options: CompletionOptions = CompletionOptions(),
    onChunk: StreamedChunk => Unit
  ): Either[LLMError, Completion] = {
    // For testing, just call complete
    complete(conversation, options)
  }
  
  def getCallCount: Int = callCount
  def resetCallCount(): Unit = { callCount = 0 }
}

object MockLLMClient {
  /**
   * Create mock with predefined responses based on query patterns.
   */
  def withResponses(responses: (String, String)*): MockLLMClient = {
    new MockLLMClient(responses.toMap)
  }
  
  /**
   * Create mock that always returns the same response.
   */
  def withFixedResponse(response: String): MockLLMClient = {
    new MockLLMClient(Map("" -> response))
  }
  
  /**
   * Create mock that fails with an error.
   */
  def withError(error: LLMError): LLMClient = new LLMClient {
    override def complete(
      conversation: Conversation,
      options: CompletionOptions
    ): Either[LLMError, Completion] = Left(error)
    
    override def streamComplete(
      conversation: Conversation,
      options: CompletionOptions,
      onChunk: StreamedChunk => Unit
    ): Either[LLMError, Completion] = Left(error)
  }
}
```

#### Workflow Integration Test

```scala
package io.github.llm4s.tripper.workflow

import cats.effect.IO
import org.scalatest.flatspec.AnyFlatSpec
import org.scalatest.matchers.should.Matchers
import workflows4s.runtime.InMemorySyncRuntime
import workflows4s.runtime.wakeup.NoOpKnockerUpper
import workflows4s.runtime.WorkflowInstanceEngine
import io.github.llm4s.tripper.testing.MockLLMClient
import io.github.llm4s.tripper.domain._

class TravelPlanningWorkflowSpec extends AnyFlatSpec with Matchers {
  
  "TravelPlanningWorkflow" should "generate travel plan with mock LLM" in {
    // Arrange
    val mockLLM: MockLLMClient = MockLLMClient.withResponses(
      "Create travel plan" -> """
        Day 1: Arrive in Paris, visit Eiffel Tower
        Day 2: Louvre Museum and Seine River cruise
        Day 3: Montmartre and Sacré-Cœur
      """.trim
    )
    
    val initialState: State = State(
      travelBrief = TravelBrief(
        destination = "Paris",
        startDate = LocalDate.of(2024, 6, 1),
        endDate = LocalDate.of(2024, 6, 3),
        budget = Some(1500.0),
        preferences = List("art", "culture")
      ),
      travelers = Travelers.empty,
      pointsOfInterest = List.empty,
      proposedPlan = None
    )
    
    val workflow: WIO.Initial = TravelPlanningWorkflow.create(mockLLM)
    
    val engine: WorkflowInstanceEngine = WorkflowInstanceEngine
      .basic()
      .withKnockerUpper(NoOpKnockerUpper)
    
    val runtime = InMemorySyncRuntime.create(workflow, initialState, engine)
    
    // Act
    val instance = runtime.createInstance("test-plan-1")
    instance.wakeup()  // Trigger workflow execution
    
    // Assert
    val finalState: State = instance.queryState()
    
    assert(finalState.proposedPlan.isDefined)
    assert(finalState.proposedPlan.get.contains("Eiffel Tower"))
    assert(finalState.proposedPlan.get.contains("Louvre Museum"))
    assert(mockLLM.getCallCount == 1)
  }
  
  it should "handle LLM errors gracefully" in {
    // Arrange
    val errorLLM: LLMClient = MockLLMClient.withError(
      LLMError.RateLimitError("Rate limit exceeded", None)
    )
    
    val initialState: State = State(
      travelBrief = TravelBrief("Paris", LocalDate.now, LocalDate.now.plusDays(3), None, List.empty),
      travelers = Travelers.empty,
      pointsOfInterest = List.empty,
      proposedPlan = None
    )
    
    val workflow: WIO.Initial = TravelPlanningWorkflow.create(errorLLM)
    val engine: WorkflowInstanceEngine = WorkflowInstanceEngine.basic().withKnockerUpper(NoOpKnockerUpper)
    val runtime = InMemorySyncRuntime.create(workflow, initialState, engine)
    
    // Act
    val instance = runtime.createInstance("test-error-1")
    instance.wakeup()
    
    // Assert
    val finalState: State = instance.queryState()
    
    assert(finalState.error.isDefined)
    assert(finalState.error.get.contains("Rate limit"))
  }
  
  it should "replay events correctly" in {
    // Arrange
    val mockLLM: MockLLMClient = MockLLMClient.withFixedResponse("Test plan")
    val workflow: WIO.Initial = TravelPlanningWorkflow.create(mockLLM)
    val engine: WorkflowInstanceEngine = WorkflowInstanceEngine.basic().withKnockerUpper(NoOpKnockerUpper)
    val runtime = InMemorySyncRuntime.create(workflow, State.empty, engine)
    
    // Act - First execution
    val instance1 = runtime.createInstance("replay-test")
    instance1.wakeup()
    val state1: State = instance1.queryState()
    
    // Get events
    val events: List[Event] = instance1.getEvents()
    
    // Replay events to new instance
    val instance2 = runtime.createInstance("replay-test-2")
    events.foreach(event => instance2.applyEvent(event))
    val state2: State = instance2.queryState()
    
    // Assert - States should be identical
    assert(state1 == state2)
  }
}
```

### Layer 3: Tool Handler Tests

**Purpose**: Test tool handlers independently.

**Tools**: ScalaTest, Mock HTTP clients for MCP

**Example**:

```scala
package io.github.llm4s.tripper.mcp

import org.scalatest.flatspec.AnyFlatSpec
import org.scalatest.matchers.should.Matchers
import org.llm4s.toolapi.SafeParameterExtractor

class MCPToolAdapterSpec extends AnyFlatSpec with Matchers {
  
  "MCPToolAdapter" should "convert MCP schema to llm4s schema" in {
    val mcpSchema: ujson.Value = ujson.Obj(
      "type" -> "object",
      "properties" -> ujson.Obj(
        "query" -> ujson.Obj(
          "type" -> "string",
          "description" -> "Search query"
        ),
        "limit" -> ujson.Obj(
          "type" -> "integer",
          "description" -> "Max results"
        )
      ),
      "required" -> ujson.Arr("query")
    )
    
    val llm4sSchema: SchemaDefinition[Map[String, Any]] = 
      MCPToolAdapter.convertSchema(mcpSchema)
    
    assert(llm4sSchema != null)
    // Additional assertions on schema structure
  }
  
  it should "handle tool parameter extraction" in {
    val params: SafeParameterExtractor = SafeParameterExtractor(
      ujson.Obj(
        "query" -> "hotels in Paris",
        "limit" -> 5
      )
    )
    
    val result: Either[String, (String, Int)] = for {
      query <- params.getString("query")
      limit <- params.getInt("limit")
    } yield (query, limit)
    
    result match {
      case Right((query, limit)) =>
        assert(query == "hotels in Paris")
        assert(limit == 5)
      case Left(error) => fail(s"Extraction failed: $error")
    }
  }
}
```

**Tools**: ScalaTest, JSON schema validation

### Layer 5: End-to-End Tests (Selective)

**Purpose**: Test with real LLM APIs for critical paths.

**When to run**: CI/CD (nightly), pre-release

**Cost mitigation**:
- Use deterministic settings (temperature=0.0)
- Cache responses
- Run selectively
- Use cheaper models (gpt-4o-mini)

**Example**:

```scala
package io.github.llm4s.tripper.e2e

import cats.effect.{IO, IOApp, ExitCode}
import org.scalatest.flatspec.AnyFlatSpec
import org.scalatest.matchers.should.Matchers
import org.scalatest.tags.Slow

@Slow
class TravelPlanningE2ESpec extends AnyFlatSpec with Matchers {
  
  // Only run when OPENAI_API_KEY is set
  val runE2E: Boolean = sys.env.contains("OPENAI_API_KEY")
  
  if (runE2E) {
    "Travel Planning Workflow" should "generate valid plan with real LLM" in {
      val test: IO[Unit] = for {
        config <- ConfigLoader.load
        client <- LLMClientFactory.createPlannerClient(config)
        
        workflow = TravelPlanningWorkflow.create(client)
        runtime <- InMemoryRuntime.default(workflow, State.empty, engine)
        
        instance <- runtime.createInstance("e2e-test-1")
        _ <- instance.wakeup()
        
        finalState <- instance.queryState()
      } yield {
        assert(finalState.proposedPlan.isDefined)
        assert(finalState.proposedPlan.get.length > 100)
        assert(finalState.error.isEmpty)
      }
      
      test.unsafeRunSync()
    }
  } else {
    it should "skip E2E test (no API key)" in {
      info("Set OPENAI_API_KEY to run E2E tests")
    }
  }
}
```

### Layer 6: Property-Based Tests

**Purpose**: Test domain invariants with ScalaCheck.

**Example**:

```scala
package io.github.llm4s.tripper.domain

import org.scalatest.flatspec.AnyFlatSpec
import org.scalatest.matchers.should.Matchers
import org.scalatestplus.scalacheck.ScalaCheckPropertyChecks
import org.scalacheck.Gen

class TravelBriefPropertySpec 
  extends AnyFlatSpec 
  with Matchers 
  with ScalaCheckPropertyChecks {
  
  val travelBriefGen: Gen[TravelBrief] = for {
    destination <- Gen.alphaStr.suchThat(_.nonEmpty)
    startDate <- Gen.choose(0L, 365L).map(days => LocalDate.now.plusDays(days))
    duration <- Gen.choose(1, 30)
    budget <- Gen.option(Gen.choose(100.0, 10000.0))
    preferences <- Gen.listOf(Gen.alphaStr)
  } yield TravelBrief(
    destination = destination,
    startDate = startDate,
    endDate = startDate.plusDays(duration),
    budget = budget,
    preferences = preferences
  )
  
  "TravelBrief" should "always have endDate >= startDate" in {
    forAll(travelBriefGen) { brief =>
      assert(!brief.endDate.isBefore(brief.startDate))
    }
  }
  
  it should "calculate correct duration" in {
    forAll(travelBriefGen) { brief =>
      val expectedDuration: Long = 
        ChronoUnit.DAYS.between(brief.startDate, brief.endDate)
      assert(brief.duration == expectedDuration)
    }
  }
}
```

## Consequences

### Positive

1. **Fast feedback**: Unit tests run in milliseconds
2. **Cost-effective**: Mock LLMs avoid API costs
3. **Deterministic**: Tests are repeatable
4. **Comprehensive coverage**: Multiple layers ensure quality
5. **workflows4s integration**: InMemorySyncRuntime enables workflow testing
6. **Isolated failures**: Each layer tests specific concerns
7. **Regression protection**: Event replay tests ensure correctness
8. **Property-based**: ScalaCheck finds edge cases

### Negative

1. **Mocking complexity**: Need to maintain mock LLM responses
2. **E2E costs**: Real API tests are expensive
3. **Non-deterministic E2E**: Real LLMs produce varied outputs
4. **Test maintenance**: More layers = more tests to maintain
5. **Mock divergence**: Mocks may not match real LLM behavior
6. **Contract brittleness**: Schema changes break tests

### Trade-offs

**Mock vs. Real LLM**:
- **Mock**: Fast, free, deterministic, but may not catch integration issues
- **Real**: Accurate, but slow, expensive, non-deterministic

**Recommendation**:
- ✅ **80% mocked** (unit + integration tests)
- ✅ **15% contract** (schema validation)
- ✅ **5% E2E** (critical paths only)

```scala
lazy val IntegrationTest = config("it") extend Test
```
