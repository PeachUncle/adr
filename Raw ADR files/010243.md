# ADR 006: Cross-Platform Global Keyboard Shortcuts

**Status:** Accepted

**Date:** 2025-10-13

**Deciders:** Development Team

## Context

Latera's core feature is saving links via a global keyboard shortcut that works system-wide, even when the app is not focused. Requirements:

- **Primary Action**: Trigger "save current link on hover" from anywhere in the OS
- **Secondary Actions**: Show/hide main window, open command palette
- **Cross-Platform**: Consistent behavior on Windows and macOS
- **Customizable**: Users can change shortcuts in settings
- **Non-Conflicting**: Avoid OS/app reserved shortcuts
- **Discoverable**: Clear documentation of default shortcuts
- **Reliable**: Must work even when app is in background/minimized

Technical Constraints:
- Works when app doesn't have focus
- Detects modifier keys (Cmd/Ctrl, Shift, Alt/Option)
- Handles keyboard layout differences
- Prevents conflicts with system shortcuts
- Must unregister on app quit

## Decision

We will use **Electron's `globalShortcut` module** with the following implementation:

### Default Keyboard Shortcuts

| Action | macOS | Windows | Description |
|--------|-------|---------|-------------|
| Save Link on Hover | `Cmd+Shift+S` | `Ctrl+Shift+S` | Capture link under mouse cursor |
| Show/Hide Window | `Cmd+Shift+L` | `Ctrl+Shift+L` | Toggle main window visibility |
| Quick Add URL | `Cmd+Shift+A` | `Ctrl+Shift+A` | Open quick add dialog |

### Implementation Architecture

```typescript
// main/shortcuts.ts
import { app, globalShortcut, BrowserWindow } from 'electron';
import { getSettings, saveSetting } from './database/settings';

interface ShortcutConfig {
  action: string;
  defaultMac: string;
  defaultWin: string;
  handler: () => void;
}

export class ShortcutManager {
  private shortcuts: Map<string, ShortcutConfig> = new Map();
  private registered: Set<string> = new Set();

  constructor(private mainWindow: BrowserWindow) {
    this.initializeShortcuts();
  }

  private initializeShortcuts() {
    this.shortcuts.set('save-link', {
      action: 'save-link',
      defaultMac: 'CommandOrControl+Shift+S',
      defaultWin: 'CommandOrControl+Shift+S',
      handler: () => this.handleSaveLink(),
    });

    this.shortcuts.set('toggle-window', {
      action: 'toggle-window',
      defaultMac: 'CommandOrControl+Shift+L',
      defaultWin: 'CommandOrControl+Shift+L',
      handler: () => this.handleToggleWindow(),
    });
  }

  async registerAll() {
    const settings = await getSettings();

    for (const [key, config] of this.shortcuts) {
      const customShortcut = settings[`shortcut.${key}`];
      const accelerator = customShortcut ||
        (process.platform === 'darwin' ? config.defaultMac : config.defaultWin);

      const success = globalShortcut.register(accelerator, config.handler);

      if (success) {
        this.registered.add(accelerator);
        console.log(`Registered shortcut: ${accelerator} for ${key}`);
      } else {
        console.error(`Failed to register shortcut: ${accelerator}`);
        // Fallback or notify user
      }
    }
  }

  unregisterAll() {
    globalShortcut.unregisterAll();
    this.registered.clear();
  }

  async updateShortcut(action: string, newAccelerator: string) {
    const config = this.shortcuts.get(action);
    if (!config) return;

    // Test if shortcut is available
    const testSuccess = globalShortcut.register(newAccelerator, () => {});
    if (!testSuccess) {
      throw new Error(`Shortcut ${newAccelerator} is already in use`);
    }
    globalShortcut.unregister(newAccelerator);

    // Save to settings
    await saveSetting(`shortcut.${action}`, newAccelerator);

    // Re-register all shortcuts
    this.unregisterAll();
    await this.registerAll();
  }

  private handleSaveLink() {
    // Trigger link capture workflow (see ADR 007)
    this.mainWindow.webContents.send('shortcut:save-link');
  }

  private handleToggleWindow() {
    if (this.mainWindow.isVisible()) {
      this.mainWindow.hide();
    } else {
      this.mainWindow.show();
      this.mainWindow.focus();
    }
  }
}

// main/index.ts
app.whenReady().then(() => {
  const mainWindow = createWindow();
  const shortcutManager = new ShortcutManager(mainWindow);

  shortcutManager.registerAll();

  app.on('will-quit', () => {
    shortcutManager.unregisterAll();
  });
});
```

## Consequences

### Positive

- **Native Integration**: Uses Electron's built-in API, no external dependencies
- **Reliable**: Works consistently across Windows and macOS
- **Simple API**: Straightforward registration/unregistration
- **Platform Abstraction**: `CommandOrControl` maps to Cmd (Mac) or Ctrl (Win)
- **Low Overhead**: No polling, event-driven
- **Customizable**: Easy to change shortcuts at runtime
- **Well-Documented**: Electron docs cover edge cases
- **No Accessibility Permissions** (Windows): Works without special permissions

### Negative

- **macOS Accessibility Permissions**: Requires user to grant accessibility access
- **Conflict Detection**: No built-in way to detect conflicts with system shortcuts
- **Registration Failures**: Silent failures if shortcut already taken
- **Limited Validation**: No way to verify shortcut is actually working
- **No Global Key State**: Can't detect if keys are held down globally
- **App Must Be Running**: Shortcuts only work while app is running (obvious but important)

### Mitigation Strategies

- **Permission Handling**: Detect and prompt for accessibility permissions on macOS
- **Fallback Shortcuts**: Provide alternative if registration fails
- **User Guidance**: Clear documentation on choosing shortcuts
- **Conflict Warnings**: Warn about common conflicts (screenshot tools, etc.)
- **Testing**: Test default shortcuts on fresh OS installs
- **Reset Option**: Allow users to reset to defaults

## Alternatives Considered

### Node.js Native Modules (uiohook-napi, nut.js)
- **Pros**: More control, can detect individual key states, works without accessibility permissions (sometimes)
- **Cons**: Platform-specific binaries, harder to maintain, security risks, build complexity, potential for key logging perception

### Platform-Specific APIs (AppleScript, Win32 API)
- **Pros**: Most powerful, lowest-level access, can do advanced detection
- **Cons**: Two completely different implementations, C++ native modules, very complex, hard to debug, not suitable for side project

### Browser Extension Approach
- **Pros**: No desktop app needed, simple distribution
- **Cons**: Can't register global shortcuts, limited to browser context, can't detect hovers outside browser

### Polling Mouse Position + Keyboard State
- **Pros**: More flexible, could detect modifier keys independently
- **Cons**: High CPU usage, inefficient, requires accessibility permissions anyway, complex implementation

## Implementation Details

### macOS Accessibility Permission Handling

```typescript
// main/permissions.ts
import { systemPreferences } from 'electron';

export const checkAccessibilityPermission = (): boolean => {
  if (process.platform !== 'darwin') return true;

  return systemPreferences.isTrustedAccessibilityClient(false);
};

export const requestAccessibilityPermission = (): void => {
  if (process.platform !== 'darwin') return;

  const trusted = systemPreferences.isTrustedAccessibilityClient(true);

  if (!trusted) {
    // Show dialog instructing user to enable accessibility
    dialog.showMessageBox({
      type: 'info',
      title: 'Accessibility Permission Required',
      message: 'Latera needs accessibility permission to register global shortcuts.',
      detail: 'Please enable Latera in System Preferences > Security & Privacy > Accessibility',
      buttons: ['Open System Preferences', 'Later'],
    }).then((result) => {
      if (result.response === 0) {
        shell.openExternal('x-apple.systempreferences:com.apple.preference.security?Privacy_Accessibility');
      }
    });
  }
};
```

### Accelerator Format

Electron uses a string-based format for shortcuts:

```typescript
// Valid accelerator examples
'CommandOrControl+X'     // Ctrl+X (Win) or Cmd+X (Mac)
'Alt+Shift+5'            // Alt+Shift+5
'CmdOrCtrl+Shift+Z'      // Same as CommandOrControl
'Super+Space'            // Windows key + Space (Win), Cmd+Space (Mac)

// Modifiers
'Command' | 'Cmd'        // macOS only
'Control' | 'Ctrl'       // All platforms
'CommandOrControl' | 'CmdOrCtrl'  // Cmd (Mac) or Ctrl (Win/Linux)
'Alt' | 'Option'         // Alt (Win/Linux) or Option (Mac)
'AltGr'                  // Windows/Linux only
'Shift'                  // All platforms
'Super'                  // Windows key (Win/Linux) or Cmd (Mac)

// Key codes
'0-9', 'A-Z', 'F1-F24'
'Plus', 'Space', 'Tab', 'Backspace', 'Delete'
'Insert', 'Return', 'Enter', 'Up', 'Down', 'Left', 'Right'
'Home', 'End', 'PageUp', 'PageDown', 'Escape', 'Esc'
'VolumeUp', 'VolumeDown', 'VolumeMute'
```

### Shortcut Settings UI

```typescript
// renderer/components/ShortcutSettings.tsx
import { useState } from 'react';

export const ShortcutSettings = () => {
  const [recording, setRecording] = useState<string | null>(null);

  const handleRecord = (action: string) => {
    setRecording(action);

    // Listen for key combination
    const handleKeyDown = (e: KeyboardEvent) => {
      e.preventDefault();

      const modifiers = [];
      if (e.metaKey) modifiers.push('CommandOrControl');
      if (e.shiftKey) modifiers.push('Shift');
      if (e.altKey) modifiers.push('Alt');

      const key = e.key.toUpperCase();
      const accelerator = [...modifiers, key].join('+');

      // Validate and save
      window.electron.shortcuts.update(action, accelerator)
        .then(() => {
          setRecording(null);
        })
        .catch((err) => {
          alert(err.message);
        });

      document.removeEventListener('keydown', handleKeyDown);
    };

    document.addEventListener('keydown', handleKeyDown);
  };

  return (
    <div>
      <h2>Keyboard Shortcuts</h2>
      <div>
        <label>Save Link on Hover</label>
        <button onClick={() => handleRecord('save-link')}>
          {recording === 'save-link' ? 'Press keys...' : 'Change'}
        </button>
      </div>
    </div>
  );
};
```

### Conflict Detection

```typescript
// main/shortcuts.ts
const COMMON_CONFLICTS = [
  'CommandOrControl+Shift+3', // macOS screenshot
  'CommandOrControl+Shift+4', // macOS screenshot selection
  'CommandOrControl+Shift+5', // macOS screenshot menu
  'CommandOrControl+Alt+Delete', // Windows task manager
  'CommandOrControl+Shift+Esc', // Windows task manager
  'Alt+F4', // Close window
  'CommandOrControl+Q', // Quit app
];

export const validateShortcut = (accelerator: string): { valid: boolean; warning?: string } => {
  if (COMMON_CONFLICTS.includes(accelerator)) {
    return {
      valid: false,
      warning: 'This shortcut conflicts with a system shortcut',
    };
  }

  // Test registration
  const success = globalShortcut.register(accelerator, () => {});
  globalShortcut.unregister(accelerator);

  if (!success) {
    return {
      valid: false,
      warning: 'This shortcut is already in use by another application',
    };
  }

  return { valid: true };
};
```

### Error Handling

```typescript
// Handle registration failures gracefully
app.whenReady().then(async () => {
  const shortcutManager = new ShortcutManager(mainWindow);

  try {
    await shortcutManager.registerAll();
  } catch (error) {
    console.error('Failed to register shortcuts:', error);

    // Show notification to user
    mainWindow.webContents.send('notification', {
      type: 'warning',
      message: 'Some keyboard shortcuts could not be registered. Please check settings.',
    });
  }
});
```

## Platform-Specific Considerations

### macOS
- Requires Accessibility permission for global shortcuts
- Cmd key is primary modifier (not Ctrl)
- System shortcuts in System Preferences can conflict
- Shortcuts work in fullscreen apps if permission granted

### Windows
- No special permissions required for global shortcuts
- Ctrl is primary modifier
- Windows key shortcuts may conflict with OS
- Shortcuts work across virtual desktops

## User Experience

### First Launch
1. App requests accessibility permission (macOS only)
2. User grants permission in System Preferences
3. App registers default shortcuts
4. Tutorial shows available shortcuts

### Settings
- Visual shortcut recorder (press keys to set)
- Conflict warnings before saving
- Reset to defaults option
- Export/import shortcut config

### Documentation
- Cheat sheet in Help menu
- First-run tutorial
- Settings panel with descriptions
- Troubleshooting guide for conflicts

## Notes

- Always unregister shortcuts when app quits to avoid ghost shortcuts
- Test shortcuts on clean OS installs to verify defaults work
- Consider providing alternative shortcuts for common conflicts
- Log registration failures for debugging
- Monitor Electron changelog for `globalShortcut` API changes
- Consider adding shortcut overlay (Cmd+/ to show shortcuts)

## Future Considerations

- **Multi-Action Shortcuts**: Chord shortcuts (e.g., Cmd+K, Cmd+S)
- **Context-Aware Shortcuts**: Different shortcuts in different app states
- **Shortcut Profiles**: Switch between shortcut sets (e.g., "Vim mode")
- **Cloud Sync**: Sync shortcut preferences across devices
- **Analytics**: Track which shortcuts are most used
