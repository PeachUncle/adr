# Design: Fuse Normalize-Project-Quantize Pipeline

## Context
The current implementation requires two passes: (1) preprocess vectors to normalize them, storing N×D floats, (2) project and quantize. By fusing all operations into one pass, we eliminate intermediate storage and improve cache locality.

## Goals / Non-Goals

### Goals
- Eliminate N×D normalized vectors storage (save 512 MB for SIFT-1M)
- Single-pass processing from raw vectors to quantized output
- Maintain testability of individual components
- Keep centroid computation and storage (needed for queries)
- No performance regression

### Non-Goals
- Not optimizing centroid computation (already SIMD optimized)
- Not changing quantization algorithm mathematics
- Not supporting multiple projections per dataset

## Decisions

### Decision 1: Unified quantizeVectorsFromRaw Function

**New API:**
```zig
pub fn quantizeVectorsFromRaw(
    raw_vectors: Matrix,           // N × D (unmodified input)
    projection: Matrix,            // D × d
    allocator: Allocator,
) !QuantizedData
```

**Returns** QuantizedData with centroid included for query processing.

### Algorithm: Fused Normalize-Project-Quantize

```zig
fn quantizeVectorsFromRaw(
    raw_vectors: Matrix,
    projection: Matrix,
    allocator: Allocator,
) !QuantizedData {
    const N = raw_vectors.rows;
    const D = raw_vectors.cols;
    const d = projection.cols;
    
    // Step 1: Compute centroid (uses existing function)
    const centroid = try computeCentroid(raw_vectors, allocator);
    errdefer allocator.free(centroid);
    
    // Step 2: Allocate outputs
    var hypercube = try Matrix.init(allocator, N, d);
    errdefer hypercube.deinit();
    
    var corrective_1 = try allocator.alloc(f32, N);
    errdefer allocator.free(corrective_1);
    
    var corrective_2 = try allocator.alloc(f32, N);
    errdefer allocator.free(corrective_2);
    
    const scale = 1.0 / @sqrt(@as(f32, @floatFromInt(d)));
    
    // Step 3: Process each vector (fused operation)
    for (0..N) |i| {
        const raw_vec = getRawVector(raw_vectors, i);
        
        // Sub-step 3a: Mean-center (temporary, on stack or small buffer)
        var temp_centered: [MAX_DIM]f32 = undefined;  // Or allocate
        var norm_sq: f32 = 0.0;
        
        for (0..D) |k| {
            const centered = raw_vec[k] - centroid[k];
            temp_centered[k] = centered;
            norm_sq += centered * centered;
        }
        
        // Sub-step 3b: Compute norm (corrective_1)
        const norm = @sqrt(norm_sq);
        corrective_1[i] = norm;
        
        // Sub-step 3c: Normalize to temp buffer
        var temp_normalized: [MAX_DIM]f32 = undefined;
        if (norm > 0.0) {
            for (0..D) |k| {
                temp_normalized[k] = temp_centered[k] / norm;
            }
        }
        
        // Sub-step 3d: Project and quantize (fused)
        corrective_2[i] = 0.0;
        const hyp_row = getHypercubeRow(hypercube, i);
        
        for (0..d) |j| {
            // Project: dot(P[:,j], temp_normalized)
            var proj_val: f32 = 0.0;
            for (0..D) |k| {
                proj_val += projection.get(k, j) * temp_normalized[k];
            }
            
            // Quantize
            hyp_row[j] = if (proj_val >= 0.0) scale else -scale;
            
            // Accumulate corrective_2
            corrective_2[i] += proj_val * hyp_row[j];
        }
    }
    
    return QuantizedData{
        .hypercube_vectors = hypercube,
        .corrective_1 = corrective_1,
        .corrective_2 = corrective_2,
        .centroid = centroid,  // NEW: Store for queries
        .dimension = d,
        .allocator = allocator,
    };
}
```

### Decision 2: Updated QuantizedData Structure

**Current:**
```zig
pub const QuantizedData = struct {
    hypercube_vectors: Matrix,
    corrective_1: []f32,
    corrective_2: []f32,
    dimension: usize,
    allocator: Allocator,
};
```

**New:**
```zig
pub const QuantizedData = struct {
    hypercube_vectors: Matrix,
    corrective_1: []f32,
    corrective_2: []f32,
    centroid: []f32,           // NEW: For query processing
    dimension: usize,
    allocator: Allocator,
    
    pub fn deinit(self: *QuantizedData) void {
        self.hypercube_vectors.deinit();
        self.allocator.free(self.corrective_1);
        self.allocator.free(self.corrective_2);
        self.allocator.free(self.centroid);  // NEW
    }
};
```

### Decision 3: Remove PreprocessedData

No longer needed since we don't store intermediate normalized vectors.

Functions removed:
- `meanCenterAndNormalize()`
- `preprocessVectors()`
- `PreprocessedData` structure

Functions kept:
- `computeCentroid()` - called internally by quantizeVectorsFromRaw

### SIMD Optimization Strategy

Maintain SIMD in critical paths:

1. **Centroid computation** (already SIMD optimized)
2. **Normalization loop** (can use SIMD for centering and norm computation)
3. **Projection dot products** (SIMD for power-of-2 dimensions >= 8)
4. **Quantization** (already SIMD with @select)

### Memory Layout Comparison

**Before Fusion:**
```
Raw vectors:    N × D (input)
Normalized:     N × D (intermediate) ← ELIMINATED
Hypercube:      N × d (output)
Corrective1:    N floats
Corrective2:    N floats
Centroid:       D floats (in PreprocessedData)
```
Total: N×(2D+d) + D+2N floats

**After Fusion:**
```
Raw vectors:    N × D (input, read-only)
Hypercube:      N × d (output)
Corrective1:    N floats
Corrective2:    N floats
Centroid:       D floats (in QuantizedData)
```
Total: N×(D+d) + D+2N floats

**Savings**: N×D floats = 512 MB for SIFT-1M

## Risks / Trade-offs

### Risk: More Complex Fusion Code
- **Mitigation**: Well-documented, step-by-step algorithm
- **Impact**: Low - algorithm is straightforward

### Trade-off: Cannot Reuse Normalized Vectors
- **Context**: User confirmed vectors projected once
- **Impact**: None

### Risk: Temporary Buffers
- **Options**: 
  1. Stack allocation (fast but size-limited)
  2. Small heap allocation per vector (flexible)
- **Decision**: Heap allocate temp buffers (D floats each)
- **Impact**: Minimal overhead, better than storing all N×D
