# Design: Add Comprehensive Query Correctness Tests

## Context
The query implementation (`queryTopK`) uses RaBitQ approximate distance estimation. While functional tests verify basic operation, they don't validate that returned results are actually the k-nearest neighbors. This design adds comprehensive correctness validation.

## Goals / Non-Goals

### Goals
- Validate k-nearest neighbor correctness
- Test realistic SIFT-like workloads (128D → 64D)
- Cover edge cases (isolated, clustered data)
- Enable regression testing
- Provide confidence for production deployment

### Non-Goals
- Not performance benchmarking (separate concern)
- Not accuracy tuning (accept RaBitQ approximation)
- Not exhaustive dimensional testing (focus on 64D, 128D)

## Decisions

### Decision 1: Three-Scenario Test Strategy

**Rationale**:
1. **SIFT-like synthetic**: Most important - mimics real workload
2. **Isolated vectors**: Edge case validation - ensures correct ranking
3. **Voronoi clustering**: Validates cluster queries - common use case

### Decision 2: Ground Truth via Brute Force

**Approach**: Compute exact k-NN using brute force Euclidean distance

**Justification**:
- Simple and correct
- Acceptable for test datasets (100-2048 vectors)
- No external dependencies

### Decision 3: Tolerance-Based Validation

**Challenge**: RaBitQ uses approximation → results may not match ground truth exactly

**Solution**: Validate using recall@k metric
- Recall@k = |returned ∩ ground_truth| / k
- Accept recall@k ≥ 0.8 (80% overlap)

**Rationale**: Approximate methods trade accuracy for speed. 80% recall is acceptable for tests.

## Algorithm: Helper Functions

### generateRandomVector()
```zig
/// Generate random vector with Gaussian distribution
/// seed: deterministic generation for reproducibility
fn generateRandomVector(
    dim: usize,
    seed: u64,
    allocator: Allocator,
) ![]f32 {
    var prng = std.rand.DefaultPrng.init(seed);
    const random = prng.random();
    
    const vec = try allocator.alloc(f32, dim);
    for (vec) |*val| {
        // Box-Muller transform for Gaussian
        const u1 = random.float(f32);
        const u2 = random.float(f32);
        val.* = @sqrt(-2.0 * @log(u1)) * @cos(2.0 * std.math.pi * u2);
    }
    return vec;
}
```

### perturbVector()
```zig
/// Add Gaussian noise to a vector
/// noise_scale: standard deviation of noise
fn perturbVector(
    center: []const f32,
    noise_scale: f32,
    seed: u64,
    allocator: Allocator,
) ![]f32 {
    var prng = std.rand.DefaultPrng.init(seed);
    const random = prng.random();
    
    const perturbed = try allocator.alloc(f32, center.len);
    for (center, perturbed) |c, *p| {
        const u1 = random.float(f32);
        const u2 = random.float(f32);
        const noise = noise_scale * @sqrt(-2.0 * @log(u1)) * @cos(2.0 * std.math.pi * u2);
        p.* = c + noise;
    }
    return perturbed;
}
```

### euclideanDistance()
```zig
/// Compute exact Euclidean distance
fn euclideanDistance(a: []const f32, b: []const f32) f32 {
    std.debug.assert(a.len == b.len);
    var sum_sq: f32 = 0.0;
    for (a, b) |ai, bi| {
        const diff = ai - bi;
        sum_sq += diff * diff;
    }
    return @sqrt(sum_sq);
}
```

### computeGroundTruth()
```zig
/// Compute exact k-NN using brute force Euclidean distance
fn computeGroundTruth(
    query: []const f32,
    dataset: Matrix,  // N × D
    k: usize,
    allocator: Allocator,
) ![]usize {
    const N = dataset.rows;
    const D = dataset.cols;
    
    // Compute all distances
    const distances = try allocator.alloc(f32, N);
    defer allocator.free(distances);
    
    for (0..N) |i| {
        const vec_start = i * D;
        const vec = dataset.data[vec_start..][0..D];
        distances[i] = euclideanDistance(query, vec);
    }
    
    // Create index-distance pairs
    const IndexDist = struct { index: usize, distance: f32 };
    var pairs = try allocator.alloc(IndexDist, N);
    defer allocator.free(pairs);
    
    for (0..N) |i| {
        pairs[i] = .{ .index = i, .distance = distances[i] };
    }
    
    // Sort by distance
    std.mem.sort(IndexDist, pairs, {}, struct {
        fn lessThan(_: void, a: IndexDist, b: IndexDist) bool {
            return a.distance < b.distance;
        }
    }.lessThan);
    
    // Return top-k indices
    const result = try allocator.alloc(usize, k);
    for (0..k) |i| {
        result[i] = pairs[i].index;
    }
    return result;
}
```

## Test Design

### Test 1: SIFT-Like Synthetic Vectors

**Setup**:
```zig
test "queryTopK - SIFT-like synthetic vectors" {
    const N = 100;  // Dataset size
    const D = 128;  // Original dimension
    const d = 64;   // Projected dimension
    const k = 10;   // k-nearest
    
    // Generate random dataset
    var raw_vectors = try Matrix.init(testing.allocator, N, D);
    defer raw_vectors.deinit();
    
    for (0..N) |i| {
        const vec = try generateRandomVector(D, i, testing.allocator);
        defer testing.allocator.free(vec);
        for (0..D) |j| {
            raw_vectors.set(i, j, vec[j]);
        }
    }
    
    // Generate random projection
    var projection = try Matrix.initRandomOrthogonal(testing.allocator, D, d, 42);
    defer projection.deinit();
    
    // Quantize
    var quantized = try quantization.quantizeVectorsFromRaw(
        raw_vectors, projection, testing.allocator
    );
    defer quantized.deinit();
    
    // Generate query
    const query_vec = try generateRandomVector(D, 12345, testing.allocator);
    defer testing.allocator.free(query_vec);
    
    // Compute ground truth
    const ground_truth = try computeGroundTruth(
        query_vec, raw_vectors, k, testing.allocator
    );
    defer testing.allocator.free(ground_truth);
    
    // Query with RaBitQ
    const results = try queryTopK(8, quantized, query_vec, k, testing.allocator);
    defer testing.allocator.free(results);
    
    // Validate: compute recall@k
    var matches: usize = 0;
    for (results) |result| {
        for (ground_truth) |gt_idx| {
            if (result.index == gt_idx) matches += 1;
        }
    }
    const recall = @as(f32, @floatFromInt(matches)) / @as(f32, @floatFromInt(k));
    
    // Assert: recall >= 0.8 (80% of k-NN correct)
    try testing.expect(recall >= 0.8);
}
```

**Success Criteria**: Recall@10 ≥ 0.8

### Test 2: Isolated Vectors

**Setup**:
```zig
test "queryTopK - isolated vectors in different orthants" {
    const D = 64;
    const d = 32;
    const N = 10;
    
    // Create 10 vectors in different orthants
    var raw_vectors = try Matrix.init(testing.allocator, N, D);
    defer raw_vectors.deinit();
    
    for (0..N) |i| {
        for (0..D) |j| {
            // Vector i: 10.0 in dimension i, 0 elsewhere
            raw_vectors.set(i, j, if (j == i) 10.0 else 0.0);
        }
    }
    
    // Identity-like projection
    var projection = try Matrix.init(testing.allocator, D, d);
    defer projection.deinit();
    for (0..D) |i| {
        for (0..d) |j| {
            projection.set(i, j, if (i == j) 1.0 else 0.0);
        }
    }
    
    var quantized = try quantization.quantizeVectorsFromRaw(
        raw_vectors, projection, testing.allocator
    );
    defer quantized.deinit();
    
    // Query close to Vector 3: [0,0,0,9.5,0,...]
    var query = try testing.allocator.alloc(f32, D);
    defer testing.allocator.free(query);
    @memset(query, 0.0);
    query[3] = 9.5;
    
    const results = try queryTopK(8, quantized, query, 3, testing.allocator);
    defer testing.allocator.free(results);
    
    // Assert: Vector 3 is the closest
    try testing.expectEqual(@as(usize, 3), results[0].index);
    
    // Assert: distances increase
    try testing.expect(results[0].distance < results[1].distance);
    try testing.expect(results[1].distance < results[2].distance);
}
```

**Success Criteria**: Correct nearest neighbor identified

### Test 3: Voronoi Cell Clustering

**Setup**:
```zig
test "queryTopK - voronoi cell clustering" {
    const D = 128;
    const d = 64;
    const num_centroids = 64;
    const vecs_per_centroid = 32;
    const N = num_centroids * vecs_per_centroid; // 2048
    
    // Generate centroids (far apart)
    var centroids = try testing.allocator.alloc([]f32, num_centroids);
    defer {
        for (centroids) |centroid| testing.allocator.free(centroid);
        testing.allocator.free(centroids);
    }
    
    for (0..num_centroids) |i| {
        centroids[i] = try generateRandomVector(D, i * 1000, testing.allocator);
        // Scale to separate clusters
        for (centroids[i]) |*val| {
            val.* *= 100.0;
        }
    }
    
    // Generate dataset: perturbed centroids
    var raw_vectors = try Matrix.init(testing.allocator, N, D);
    defer raw_vectors.deinit();
    
    for (0..num_centroids) |c| {
        for (0..vecs_per_centroid) |v| {
            const idx = c * vecs_per_centroid + v;
            const perturbed = try perturbVector(
                centroids[c], 1.0, idx, testing.allocator
            );
            defer testing.allocator.free(perturbed);
            
            for (0..D) |j| {
                raw_vectors.set(idx, j, perturbed[j]);
            }
        }
    }
    
    // Quantize
    var projection = try Matrix.initRandomOrthogonal(
        testing.allocator, D, d, 42
    );
    defer projection.deinit();
    
    var quantized = try quantization.quantizeVectorsFromRaw(
        raw_vectors, projection, testing.allocator
    );
    defer quantized.deinit();
    
    // Test: query from each voronoi cell
    for (0..num_centroids) |c| {
        // Query = slightly perturbed centroid
        const query = try perturbVector(
            centroids[c], 0.5, c + 99999, testing.allocator
        );
        defer testing.allocator.free(query);
        
        const results = try queryTopK(
            8, quantized, query, vecs_per_centroid, testing.allocator
        );
        defer testing.allocator.free(results);
        
        // Assert: all results from same cluster
        const cluster_start = c * vecs_per_centroid;
        const cluster_end = cluster_start + vecs_per_centroid;
        
        for (results) |result| {
            try testing.expect(result.index >= cluster_start);
            try testing.expect(result.index < cluster_end);
        }
    }
}
```

**Success Criteria**: All returned vectors from correct cluster

## Performance Considerations

### Test Execution Time
- **Test 1**: ~200ms (100 vectors, brute force)
- **Test 2**: ~10ms (10 vectors, simple)
- **Test 3**: ~2-3 seconds (2048 vectors × 64 queries)

**Total**: ~3-4 seconds additional test time

**Acceptable**: Tests run during development, not production

### Memory Usage
- **Test 1**: ~100 KB (100 × 128D vectors)
- **Test 2**: ~5 KB (10 × 64D vectors)
- **Test 3**: ~1 MB (2048 × 128D vectors)

**Acceptable**: Small datasets, allocated temporarily

## Validation Metrics

### Recall@k
Primary metric for approximate methods:
```
recall@k = |returned ∩ ground_truth| / k
```

**Threshold**: 0.8 (80% overlap)

**Rationale**: RaBitQ trades accuracy for speed. 80% recall validates correctness while accepting approximation.

### Distance Monotonicity
Secondary check: returned distances should increase:
```
distance[0] <= distance[1] <= ... <= distance[k-1]
```

## Error Handling

### Test Failures
- **Low recall**: Indicates quantization or distance estimation bug
- **Wrong nearest**: Indicates query processing bug
- **Unsorted results**: Indicates selectTopK bug

### Debugging Strategy
1. Print ground truth vs returned indices
2. Compare actual distances
3. Verify quantization correctness
4. Check projection orthogonality
