# ADR 0001: Architecture Foundations

- Status: Accepted (2025-09-16)
- Deciders: Core Engineering Team
- Tags: architecture, build, tooling

## Context
We needed a lightweight, fast iteration platform with strong DX, fast HMR, modern ESM output, and straightforward bundle analysis to prototype and productionize the NIL Transparency Network dashboard. Requirements also included:
- Rapid UI iteration with React 18 (Concurrent-ready)
- First-class TypeScript support
- Tailwind utility design tokens with CSS variables
- Simple code splitting & lazy loading for panels
- Easy integration of accessibility & testing tooling
- Ability to enforce performance budgets early

## Decision
Adopt Vite 5 + React 18 + TypeScript + Tailwind v3 as the core stack. Use lazy-loaded panel modules for heavier dashboard segments. Add Vitest + Testing Library + jest-dom for test foundation. Introduce bundle analyzer behind an explicit `analyze` mode. Maintain ADRs under `docs/adr`.

## Consequences
### Positive
- Fast developer feedback loop (Vite + HMR)
- Clear separation of baseline UI vs. heavy feature panels
- Early observability into bundle composition
- Test setup encourages accessibility assertions
- Governance (ADR, contributing, changelog) improves maintainability

### Negative
- Vite ecosystem changes can require periodic config maintenance
- Need to watch size creep in vendor chunk (React + Radix + icons)
- Tailwind + many UI primitives can bloat CSS if not curated

### Neutral / Mitigations
- Performance budgets script ensures drift is caught early
- Analyzer only runs on demand to keep builds fast by default

## Alternatives Considered
1. Next.js: Heavier routing/static requirements not yet needed.
2. Create React App: Deprecated and slower build pipeline.
3. Webpack custom config: Higher maintenance cost without clear benefit here.
4. Tailwind v4 preview: Caused instability; reverted to stable v3 for reliability.

## Follow Ups
- Add additional ADR for compliance engine integration strategy.
- Evaluate migration to React 19 once stable for further concurrent features.
