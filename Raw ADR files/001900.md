# ADR-001: Asynchronous Smart Agent Report Generation with Server Actions

**Status:** Implemented  
**Date:** 2024-03-25  
**Author:** UX AI Auditor Team  

## Context

The current synchronous report generation system has a significant disadvantage: long generation times (30-120 seconds) which leads to:
- Poor user experience with long waiting times
- Risk of request timeouts
- Inability to handle complex analyses that might take several minutes
- Server resource blocking during generation

The new AI agent API provides more comprehensive analysis but requires even more processing time, making the synchronous approach unsustainable.

## Decision

We will implement an asynchronous report generation system using:
1. **State Machine Pattern** for managing report lifecycle (generating, success, error)
2. **Server Actions** for all backend operations instead of API routes
3. **Background Jobs** for report generation using client-side intervals
4. **Client-side Polling** for real-time status updates
5. **Dual Mode Support** maintaining backward compatibility with existing "classic" reports
6. **OpenAPI Integration** with the UX AI Auditor API following the specification in `artifacts/ADR/src/openapi.json`

```typescript
export async function startSmartAnalysis(
  url: string, 
  analysisType: string = "ux_auditor"
): Promise<StartSmartAnalysisResult> {
  const session = await auth();
  
  if (!session?.user?.id) {
    redirect("/login");
  }

  // Validate URL format
  try {
    new URL(url);
  } catch {
    return { success: false, error: "Invalid URL format" };
  }

  // Create report with pending status
  const report = await db.report.create({
    data: {
      userId: session.user.id,
      url,
      type: ReportType.SMART_AGENT,
      status: ReportStatus.PENDING,
      metadata: {
        analysisType,
        requestedAt: new Date().toISOString(),
        estimatedTime: 120
      }
    }
  });

  // Create job for processing
  await db.reportGenerationJob.create({
    data: {
      reportId: report.id
    }
  });

  return {
    success: true,
    reportId: report.id,
    message: "Анализ запущен. Умный агент изучает ваш сайт..."
  };
}
```

#### 2. Check Report Status
```typescript
export async function getReportStatus(reportId: string): Promise<ReportStatusResult> {
  const session = await auth();
  
  if (!session?.user?.id) {
    return { success: false, error: "Unauthorized" };
  }

  const report = await db.report.findFirst({
    where: {
      id: reportId,
      userId: session.user.id
    }
  });

  if (!report) {
    return { success: false, error: "Report not found" };
  }

  // Return different responses based on status
  switch (report.status) {
    case ReportStatus.PENDING:
      return {
        success: true,
        reportId: report.id,
        status: report.status,
        message: "Анализ в очереди на обработку..."
      };

    case ReportStatus.GENERATING:
      return {
        success: true,
        reportId: report.id,
        status: report.status,
        progress: report.metadata?.progress ?? 0,
        currentStep: report.metadata?.currentStep ?? "Анализ в процессе...",
        estimatedTimeRemaining: calculateRemainingTime(report)
      };

    case ReportStatus.SUCCESS:
      return {
        success: true,
        reportId: report.id,
        status: report.status,
        report: report.report as SmartAgentResponse
      };

    case ReportStatus.ERROR:
      return {
        success: true,
        reportId: report.id,
        status: report.status,
        error: report.error,
        canRetry: true
      };
  }
}
```

#### 3. Smart Agent API Integration

```typescript
// Real Smart Agent API integration using OpenAPI specification and env.js
async function callSmartAgentAPI({
  url,
  analysis_type,
  onProgress
}: {
  url: string;
  analysis_type: string;
  onProgress?: (progress: number, step: string) => Promise<void>;
}): Promise<SmartAgentResponse> {
  
  if (!API_KEY) {
    throw new Error("API_API_KEY is not configured in environment");
  }

  try {
    // 1. Start analysis using POST /api/v2/api/analyze (from OpenAPI spec)
    const analyzeRequest = {
      url,
      analysis_type: analysis_type as AnalysisType,
      output_format: ["json"]
    };

    if (onProgress) {
      await onProgress(5, "Запуск анализа через Smart Agent API...");
    }

    const analyzeResponse = await fetch(`${API_BASE_URL}/api/v2/api/analyze`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'X-API-Key': API_KEY  // Using X-API-Key header (recommended)
      },
      body: JSON.stringify(analyzeRequest)
    });

    if (!analyzeResponse.ok) {
      throw new Error(`API Error: ${analyzeResponse.status} ${analyzeResponse.statusText}`);
    }

    const analysisResponse = await analyzeResponse.json();
    const { analysis_id } = analysisResponse;

    if (onProgress) {
      await onProgress(10, "Анализ запущен, ожидание результатов...");
    }

    // 2. Poll for results using GET /api/v2/api/analysis/{analysis_id}
    let result = null;
    let attempts = 0;
    const maxAttempts = 120; // 10 minutes with 5-second intervals
    
    while (attempts < maxAttempts) {
      const statusResponse = await fetch(
        `${API_BASE_URL}/api/v2/api/analysis/${analysis_id}`,
        {
          headers: {
            'X-API-Key': API_KEY
          }
        }
      );

      if (!statusResponse.ok) {
        throw new Error(`Status check failed: ${statusResponse.status}`);
      }

      const statusData = await statusResponse.json();
      
      if (statusData.status === 'completed' && statusData.result) {
        result = statusData.result;
        if (onProgress) {
          await onProgress(100, "Анализ завершен успешно!");
        }
        break;
      } else if (statusData.status === 'failed') {
        throw new Error(statusData.error ?? 'Analysis failed');
      }
      
      // Update progress based on attempts
      if (onProgress) {
        const progress = Math.min(10 + (attempts / maxAttempts) * 80, 95);
        const step = statusData.status === 'processing' 
          ? "Умный агент анализирует ваш сайт..." 
          : "Ожидание начала анализа...";
        await onProgress(progress, step);
      }
      
      await new Promise(resolve => setTimeout(resolve, 5000)); // Wait 5 seconds
      attempts++;
    }
    
    if (!result) {
      throw new Error('Analysis timeout - please try again');
    }

    // Return the result directly as it already matches SmartAgentResponse format
    return result as SmartAgentResponse;

  } catch (error) {
    console.error('Smart Agent API Error:', error);
    throw error;
  }
}
```

```typescript
// src/actions/smart-agent.ts
export async function processReportQueue(): Promise<{ success: boolean; processed: number; error?: string }> {
  try {
    console.log("Report processor started");

    // Check API health first using /api/v2/api/health
    const isHealthy = await checkSmartAgentHealth();
    if (!isHealthy) {
      console.warn("Smart Agent API is not healthy, skipping processing");
      return { success: false, processed: 0, error: "API not available" };
    }

    // 1. Fetch pending jobs from queue using Prisma
    const pendingJobs = await db.reportGenerationJob.findMany({
      where: {
        report: {
          status: ReportStatus.PENDING
        },
        OR: [
          { nextRetryAt: null },
          { nextRetryAt: { lte: new Date() } }
        ]
      },
      include: { 
        report: true 
      },
      take: 3 // Process fewer jobs at once for API rate limiting
    });

    console.log(`Found ${pendingJobs.length} pending jobs`);

    // 2. Process each job
    for (const job of pendingJobs) {
      try {
        console.log(`Processing job ${job.id} for report ${job.reportId}`);

        // Update status to generating
        await db.report.update({
          where: { id: job.reportId },
          data: { 
            status: ReportStatus.GENERATING,
            startedAt: new Date(),
            metadata: {
              progress: 0,
              currentStep: "Инициализация анализа...",
              analysisType: job.report.metadata?.analysisType ?? "ux_auditor"
            }
          }
        });

        // Call the Smart Agent API with progress updates
        const result = await callSmartAgentAPI({
          url: job.report.url,
          analysis_type: job.report.metadata?.analysisType ?? "ux_auditor",
          onProgress: async (progress: number, step: string) => {
            // Update progress in real-time
            await db.report.update({
              where: { id: job.reportId },
              data: {
                metadata: {
                  progress,
                  currentStep: step,
                  analysisType: job.report.metadata?.analysisType ?? "ux_auditor"
                }
              }
            });
          }
        });

        // Save successful result
        await db.report.update({
          where: { id: job.reportId },
          data: {
            status: ReportStatus.SUCCESS,
            report: result,
            completedAt: new Date()
          }
        });

        // Clean up job
        await db.reportGenerationJob.delete({
          where: { id: job.id }
        });

      } catch (error) {
        // Handle errors with retry logic
        await handleJobError(job, error);
      }
    }

    return { 
      success: true, 
      processed: pendingJobs.length 
    };
  } catch (error) {
    console.error('Report processor error:', error);
    return { 
      success: false, 
      processed: 0, 
      error: error instanceof Error ? error.message : "Unknown error" 
    };
  }
}
```

#### State Management Hook
```typescript
// src/hooks/useSmartReport.ts
export function useSmartReport(reportId: string | null) {
  const [state, setState] = useState<SmartReportState>({ 
    status: ReportStatus.PENDING 
  });

  useEffect(() => {
    if (!reportId) return;

    let pollInterval: NodeJS.Timeout;

    const pollStatus = async () => {
      try {
        const result = await getReportStatus(reportId);
        
        if (!result.success) {
          throw new Error(result.error ?? 'Failed to get status');
        }
        
        setState(prevState => ({
          ...prevState,
          status: result.status ?? ReportStatus.PENDING,
          progress: result.progress,
          currentStep: result.currentStep,
          estimatedTimeRemaining: result.estimatedTimeRemaining,
          message: result.message,
          report: result.report,
          error: result.error ? new Error(result.error.message ?? result.error) : undefined
        }));
        
        // Stop polling if complete
        if (result.status === ReportStatus.SUCCESS || result.status === ReportStatus.ERROR) {
          clearInterval(pollInterval);
        }
      } catch (error) {
        console.error('Error polling report status:', error);
        setState(prevState => ({
          ...prevState,
          status: ReportStatus.ERROR,
          error: error instanceof Error ? error : new Error('Unknown error')
        }));
        clearInterval(pollInterval);
      }
    };

    // Initial poll
    pollStatus();

    // Set up polling interval (every 2 seconds)
    pollInterval = setInterval(pollStatus, 2000);

    return () => {
      if (pollInterval) {
        clearInterval(pollInterval);
      }
    };
  }, [reportId]);

  return {
    ...state,
    isLoading: state.status === ReportStatus.PENDING || state.status === ReportStatus.GENERATING,
    isComplete: state.status === ReportStatus.SUCCESS,
    hasError: state.status === ReportStatus.ERROR
  };
}
```

## Consequences

### Positive
- **Better UX**: Users can navigate away and return later
- **Scalability**: Server doesn't block during generation
- **Reliability**: Built-in retry mechanism for failures
- **Feature-rich**: Enables more complex analyses that take longer
- **Progress tracking**: Users see real-time progress
- **Better Authentication**: Server actions handle session context automatically
- **Type Safety**: Full TypeScript support with proper return types
- **Simplified Architecture**: No API route boilerplate needed
- **Performance**: Direct database access without HTTP overhead
- **Environment Integration**: Uses existing env.js configuration
- **OpenAPI Compliance**: Follows standard API specification
- **Rich Response Format**: Detailed analysis with sections, findings, and quick wins
- **Multiple Authentication Methods**: Flexible API key authentication

### Negative
- **Complexity**: More moving parts (jobs, polling, state management)
- **Database overhead**: Additional tables and queries
- **Delayed gratification**: Users must wait for results
- **Resource usage**: Continuous polling from clients
- **Background Processing**: Requires client-side intervals instead of true cron jobs
- **API Dependency**: Relies on external UX AI Auditor API availability

### Mitigation Strategies
- Use WebSockets/SSE for real-time updates instead of polling
- Implement smart caching to reduce server action calls
- Add email/push notifications for report completion
- Provide accurate time estimates based on historical data
- Consider external cron service for production background processing
- Implement API health monitoring and fallback mechanisms
