# ADR 001: Tech Stack Selection

## Status
Approved (2026-01-08)

## Context
The Best List is a greenfield multi-user todo application with AI integration, keyboard shortcuts, and mobile-first design. We need to select a technology stack that supports:

- Multi-user collaboration with permissions/ACLs
- Real-time updates and mobile responsiveness
- AI/LLM integration with user-managed API keys
- Rapid development with type safety
- Easy deployment to Railway

## Decision

### Frontend & Framework
- **Next.js 16** with App Router
  - Server and client components for optimal performance
  - Built-in routing and API routes
  - Excellent TypeScript support
  - Server-side rendering for SEO and initial load performance

- **TypeScript**
  - Type safety across the entire stack
  - Better developer experience with autocomplete and refactoring

- **Tailwind CSS**
  - Utility-first CSS for rapid UI development
  - Excellent mobile-responsive utilities
  - Small bundle size with purging

- **shadcn/ui**
  - Accessible, customizable component library
  - Built on Radix UI primitives
  - Excellent keyboard navigation support
  - Copy-paste components (no npm bloat)

### Backend & Database
- **tRPC**
  - End-to-end type safety between frontend and backend
  - No code generation needed
  - Works seamlessly with Next.js
  - Eliminates API contract drift

- **Prisma ORM**
  - Type-safe database queries
  - Excellent migration system
  - Schema-first approach with auto-generated types
  - Great PostgreSQL support

- **PostgreSQL**
  - Robust relational database for complex queries
  - Excellent support for multi-tenancy patterns
  - JSONB for flexible schema where needed
  - Railway has first-class PostgreSQL support

- **NextAuth.js**
  - Industry-standard authentication for Next.js
  - Support for multiple providers
  - Session management built-in
  - Easy integration with Prisma

### Testing
- **Vitest**
  - Fast unit and integration testing
  - Jest-compatible API
  - Native ESM support
  - Better Vite integration than Jest

- **Playwright**
  - Reliable E2E testing
  - Cross-browser support
  - Mobile viewport testing
  - Great debugging tools

- **React Testing Library**
  - Component testing best practices
  - User-centric test approach
  - Works well with Vitest

### Hosting
- **Railway**
  - Simple deployment workflow
  - Automatic PostgreSQL provisioning
  - Environment variable management
  - Cost-effective for side projects

## Consequences

### Positive
- Type safety across the entire stack reduces runtime errors
- Modern tooling with excellent DX
- Scalable architecture for multi-user features
- Easy to add AI integrations via API routes
- Mobile-first responsive design out of the box
- TDD-friendly testing infrastructure

### Negative
- Next.js 16 is relatively new - may have edge cases
- tRPC adds learning curve for contributors unfamiliar with it
- Railway pricing may increase with scale (can migrate if needed)

### Neutral
- Will need to design permission system on top of NextAuth
- LLM API key encryption strategy needed (future ADR)
- Novel organization paradigms will require custom UI components

## Alternatives Considered

### Remix instead of Next.js
- Excellent framework but Next.js has larger ecosystem and better Railway support

### GraphQL instead of tRPC
- More mature but requires code generation and lacks end-to-end type inference

### Supabase instead of Prisma + PostgreSQL
- Excellent BaaS but wanted more control over schema and migrations

### Jest instead of Vitest
- More mature but slower and less modern ESM support
