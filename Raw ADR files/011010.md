# ADR-002: Privacy-First Architecture Design

## Status
**Accepted** - January 2024

## Context

The Marina system processes highly sensitive personal information including voice recordings, emotional states, and therapeutic conversations. Privacy protection is not just a regulatory requirement but a fundamental ethical obligation for a therapeutic AI system.

Key requirements:
1. **Data Minimization**: Process only necessary data for therapeutic purposes
2. **Local Processing**: Prefer on-premises processing over cloud services
3. **PII Protection**: Automatic detection and redaction of personal information
4. **Consent Management**: Clear user control over data usage
5. **Right to Erasure**: Complete data deletion on user request
6. **Audit Transparency**: Full traceability of data processing decisions

Legal and Regulatory Context:
- **GDPR Compliance**: European data protection requirements
- **Healthcare Privacy**: Medical data protection standards
- **Russian Data Localization**: Local data processing requirements
- **Therapeutic Ethics**: Professional standards for mental health data

## Decision

We will implement a **Privacy-by-Design** architecture with the following core principles:

### 1. Local-First Processing
- **Default Local**: All STT, TTS, and LLM processing on local infrastructure
- **Conditional External**: External APIs only when explicitly required by routing logic
- **Context Minimization**: Send minimum viable context to external services
- **Immediate Purge**: External processing data deleted immediately after use

### 2. Multi-Layer PII Protection
- **Input Sanitization**: Real-time PII detection and masking
- **Processing Isolation**: Separate processing environments by sensitivity level
- **Output Filtering**: Response validation and PII removal
- **Audit Trail**: Complete log of all PII handling decisions

### 3. Graduated Data Access
- **Functional Separation**: Different system components access only necessary data
- **Temporal Limits**: Automatic data expiration and purging
- **Role-Based Access**: Administrative access controls
- **Consent-Based Processing**: User-controlled data usage permissions

### Data Classification Framework

```python
from enum import Enum

class DataSensitivity(Enum):
    PUBLIC = "public"           # Non-sensitive system data
    INTERNAL = "internal"       # System operational data  
    CONFIDENTIAL = "confidential"  # User preferences, anonymized insights
    RESTRICTED = "restricted"   # Personal conversations, voice data
    HIGHLY_RESTRICTED = "highly_restricted"  # Crisis data, medical references

class ProcessingLocation(Enum):
    LOCAL_ONLY = "local_only"
    LOCAL_PREFERRED = "local_preferred"  
    EXTERNAL_ALLOWED = "external_allowed"
    EXTERNAL_REQUIRED = "external_required"

# Data classification rules
DATA_RULES = {
    DataSensitivity.HIGHLY_RESTRICTED: ProcessingLocation.LOCAL_ONLY,
    DataSensitivity.RESTRICTED: ProcessingLocation.LOCAL_PREFERRED,
    DataSensitivity.CONFIDENTIAL: ProcessingLocation.LOCAL_PREFERRED,
    DataSensitivity.INTERNAL: ProcessingLocation.EXTERNAL_ALLOWED,
    DataSensitivity.PUBLIC: ProcessingLocation.EXTERNAL_ALLOWED
}
```

### PII Detection and Redaction Pipeline

```python
class PIIProcessor:
    def __init__(self):
        self.detectors = [
            NameDetector(),
            PhoneDetector(), 
            EmailDetector(),
            AddressDetector(),
            MedicalTermDetector(),
            PersonalIdentifierDetector()
        ]
        
    async def scan_and_redact(self, text: str, context: ProcessingContext) -> RedactionResult:
        """Detect and redact PII based on processing context"""
        detections = []
        redacted_text = text
        
        for detector in self.detectors:
            if detector.applies_to_context(context):
                detection = await detector.detect(redacted_text)
                if detection.confidence > context.threshold:
                    redacted_text = detector.redact(redacted_text, detection)
                    detections.append(detection)
        
        return RedactionResult(
            original_text=text,
            redacted_text=redacted_text,
            detections=detections,
            confidence=min([d.confidence for d in detections] or [1.0])
        )
```

### Processing Decision Engine

```python
class PrivacyDecisionEngine:
    async def can_process_externally(
        self, 
        data: str, 
        context: ProcessingContext,
        user_consent: ConsentProfile
    ) -> ProcessingDecision:
        """Determine if data can be processed by external services"""
        
        # Step 1: Data sensitivity classification
        sensitivity = await self.classify_sensitivity(data, context)
        
        # Step 2: Check data rules
        location_requirement = DATA_RULES[sensitivity]
        if location_requirement == ProcessingLocation.LOCAL_ONLY:
            return ProcessingDecision(
                allowed=False,
                reason="Data classified as local-only processing"
            )
        
        # Step 3: User consent validation
        if not user_consent.allows_external_processing:
            return ProcessingDecision(
                allowed=False,
                reason="User has not consented to external processing"
            )
        
        # Step 4: Context minimization check
        if context.requires_full_history and sensitivity >= DataSensitivity.RESTRICTED:
            return ProcessingDecision(
                allowed=False,
                reason="Full context required but contains sensitive data"
            )
        
        # Step 5: PII redaction requirement
        pii_result = await self.pii_processor.scan_and_redact(data, context)
        if pii_result.confidence < 0.9:
            return ProcessingDecision(
                allowed=False,
                reason="Cannot achieve sufficient PII redaction confidence"
            )
        
        return ProcessingDecision(
            allowed=True,
            redacted_data=pii_result.redacted_text,
            audit_info=AuditInfo(
                original_length=len(data),
                redacted_length=len(pii_result.redacted_text),
                pii_types_detected=[d.type for d in pii_result.detections],
                processing_timestamp=datetime.utcnow()
            )
        )
```

### Consent Management System

```python
class ConsentProfile:
    def __init__(self, user_id: str):
        self.user_id = user_id
        self.consents = {
            'voice_processing': ConsentItem(required=True),
            'conversation_storage': ConsentItem(required=True),
            'affective_analysis': ConsentItem(required=True),
            'external_escalation': ConsentItem(required=False, default=False),
            'anonymized_research': ConsentItem(required=False, default=False),
            'usage_analytics': ConsentItem(required=False, default=True),
            'crisis_intervention': ConsentItem(required=True, irrevocable=True)
        }
    
    def allows_external_processing(self) -> bool:
        return self.consents['external_escalation'].granted
    
    def allows_research_use(self) -> bool:
        return self.consents['anonymized_research'].granted
    
    async def update_consent(self, consent_type: str, granted: bool) -> bool:
        """Update consent with validation and audit logging"""
        consent = self.consents.get(consent_type)
        if not consent:
            raise ValueError(f"Unknown consent type: {consent_type}")
        
        if consent.irrevocable and not granted:
            raise ValueError(f"Cannot revoke required consent: {consent_type}")
        
        old_value = consent.granted
        consent.granted = granted
        consent.updated_at = datetime.utcnow()
        
        # Log consent change
        await self.audit_logger.log_consent_change(
            user_id=self.user_id,
            consent_type=consent_type,
            old_value=old_value,
            new_value=granted,
            timestamp=consent.updated_at
        )
        
        return True
```

### External Service Integration with Privacy Controls

```python
class PrivateExternalService:
    def __init__(self, service_name: str, privacy_config: PrivacyConfig):
        self.service_name = service_name
        self.privacy_config = privacy_config
        self.audit_logger = AuditLogger(service_name)
    
    async def process_with_privacy(
        self, 
        request_data: str,
        context: ProcessingContext,
        user_consent: ConsentProfile
    ) -> ExternalServiceResult:
        """Process data through external service with privacy controls"""
        
        # Step 1: Privacy decision check
        decision = await privacy_engine.can_process_externally(
            request_data, context, user_consent
        )
        
        if not decision.allowed:
            raise PrivacyViolationError(decision.reason)
        
        # Step 2: Context minimization
        minimal_context = self._minimize_context(
            decision.redacted_data, 
            context.requirements
        )
        
        # Step 3: Audit pre-processing
        request_id = await self.audit_logger.log_external_request(
            user_id=context.user_id,
            data_size=len(minimal_context),
            pii_types=decision.audit_info.pii_types_detected,
            processing_reason=context.processing_reason
        )
        
        try:
            # Step 4: External service call
            result = await self._call_external_service(minimal_context)
            
            # Step 5: Response validation and filtering
            filtered_response = await self._filter_response(result.response)
            
            # Step 6: Immediate cleanup
            await self._cleanup_external_data(request_id)
            
            # Step 7: Audit post-processing
            await self.audit_logger.log_external_response(
                request_id=request_id,
                response_size=len(filtered_response),
                processing_success=True
            )
            
            return ExternalServiceResult(
                response=filtered_response,
                metadata=result.metadata,
                privacy_audit=decision.audit_info
            )
            
        except Exception as e:
            await self.audit_logger.log_external_error(request_id, str(e))
            raise
```

## Consequences

### Positive Outcomes:
1. **Regulatory Compliance**: Meets GDPR, healthcare privacy, and local data protection laws
2. **User Trust**: Transparent privacy controls build user confidence
3. **Risk Mitigation**: Minimizes data breach impact through multiple protection layers
4. **Competitive Advantage**: Privacy-first approach differentiates from cloud-based solutions
5. **Operational Control**: Full control over data processing and retention

### Challenges and Trade-offs:
1. **Performance Impact**: Local processing may increase latency (~500ms additional)
2. **Infrastructure Costs**: Higher on-premises infrastructure requirements
3. **Complexity**: Additional engineering effort for privacy controls (~20% development overhead)
4. **Feature Limitations**: Some advanced AI features may be limited without cloud services
5. **Maintenance Overhead**: Additional operational complexity for key management and compliance

### Risk Mitigation:
1. **Performance**: Optimize local models and implement efficient caching
2. **Costs**: Justify with premium pricing for privacy-conscious users
3. **Complexity**: Invest in automation and comprehensive testing
4. **Features**: Gradual enhancement of local AI capabilities
5. **Operations**: Dedicated privacy and security operations team

## Compliance and Auditing

### Regular Compliance Checks:
- **Weekly**: Automated privacy control validation
- **Monthly**: Data retention policy enforcement audit  
- **Quarterly**: External privacy assessment
- **Annually**: Full compliance certification review

- **Privacy Control Uptime**: >99.9%
- **Audit Trail Completeness**: 100% of processing decisions logged
